# NAS Mount Android v0.1.61 — 중복 자막·NFO 숨김 설정 UI 정리

## 변경 요청

v0.1.60의 설정 → 동영상·자막 탭에서 보이던
자막·NFO 파일 숨기기 구역 전체를 사용자 설정 화면에서만 제거.
동영상 폴더 지정 및 실제 자막·NFO 숨김 동작은 유지.

## 설정 화면에서 제거된 항목

- 자막·NFO 파일 숨기기 섹션 제목 및 안내
- 등록 폴더에서 자막·TXT·NFO 파일 숨기기 체크박스
- 방금 열었던 폴더 추가
- 휴대폰/SD 폴더 추가
- 고급: 네트워크 폴더 직접 지정
- 등록된 폴더 전체 경로/원격 계정 식별자 목록과 삭제 버튼

이제 자막 글꼴 미리보기 다음에 코덱·호환성 설정으로 연결됩니다.
동영상 플레이어, 자막 기본 설정, 등록 글꼴, 코덱 설정은 유지.

## 내부적으로 보존된 기능

- MainActivity의 폴더 길게 누르기 → 더 보기 → 폴더 용도 설정
  → 동영상 폴더 지정/해제 기존 동작 그대로 유지.
- PlayerSettings.HIDE_SUBTITLES / PlayerSettings.HIDE_FOLDERS
  저장값 및 hideThisFile 필터링 로직 변경 없음.
- 이전 버전에서 지정한 동영상 폴더 목록도 삭제하지 않음.
- 등록 동영상 폴더의 자막·TXT·NFO 파일은 기존대로 목록에서만 숨김.
  실제 파일을 삭제하는 작업은 수행하지 않음.
- 설정 액티비티의 이전 폴더 선택 콜백 등 내부 호환성 코드는
  데이터 및 회귀 위험을 피하기 위해 유지하되, UI에서는 노출하지 않음.
- 책갈피·읽던 위치·영상 시청 기록·폴더별 뷰어 설정 모두 보존.

## 검증 계획

- SettingsActivity.render()에서 위 모든 UI 위젯 생성 코드 제거 확인
- MainActivity 및 PlayerSettings 파일·숨김 정책 변경 없음 확인
- JUnit, Android Lint Debug, Lint Vital Release, Release APK 빌드
- 배포 APK 서명, 앱 버전, Y 드라이브 복사 SHA256 일치 확인

연결된 실기기가 없는 경우 실제 갤럭시 폴드 UI 상태는
사용자 설치 이후 확인해야 합니다.
