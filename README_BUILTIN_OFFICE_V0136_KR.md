# NAS Mount Android v0.1.36 - 내부 오피스 편집과 압축 자동 폴더명

## v0.1.35 외부 앱 연결 방식 폐기

- 파일을 열 때 다른 편집 APK를 호출하던 방식 대신 새 BuiltInOfficeActivity를 사용.
- OfficeBridgeActivity 이전 코드는 회귀 참고용으로 남아 있으나 매니페스트에서
  해제하고 메인 파일 열기 코드에서 더 이상 호출하지 않음.
- 외부 오피스 앱 설치 없이 NAS Mount 화면 안에서 문서를 읽고 수정함.

## HWP / HWPX 엔진

- rhwp 0.9.0 (MIT) 사전 컴파일 오프라인 Studio WASM·JS/CSS를 APK에 포함.
- @rhwp/editor 0.9.0 (MIT) SDK 역시 APK에 포함하여 HWP/HWPX 문서
  열기, 내부 편집, HWP/HWPX 직렬화 실행.
- 편집 서버, CDN 또는 다른 오피스 APK를 호출하지 않음.
- 폰트는 기기에 설치된 글꼴로 대체할 수 있어 원본과 조판이 다를 수 있음.

## Excel XLS / XLSX / ODS

- SheetJS 기반 @e965/xlsx 0.20.3 (Apache-2.0) 브라우저용 엔진을 로컬 번들.
- 내부 셀 그리드에서 시트 전환, 셀 위치 이동, 숫자·문자열·수식 수정,
  원본 형식으로 내보내기를 제공. 55행 x 12열 뷰포트 이동.
- 셀 수식의 즉시 재계산, 피벗, 매크로, 고급 서식·차트 1:1 보존은
  미구현. 직렬화 과정에서 서식과 일부 구조가 바뀔 수 있음.
- LibreOffice/Collabora의 전체 네이티브 코어를 내장한 것은 아님.
  원본 네이티브 Android 빌드는 Linux/macOS 별도 대규모 구축이 필요함.
- 따라서 이번 버전은 외부 앱 없이 돌아가는 내장 베타 편집기임.

## 원본 저장 처리

- 64MiB 이하 문서를 사설 캐시로 스테이징하고, 편집된 데이터를
  청크 단위로 Java에 전달. 완전 수신 후 기존 RemoteProvider 업로드와
  overwrite=true 정책을 재사용.
- 원격 저장소 계정/PAT/ndus는 WebView에 공개하지 않음.
- WebView는 APK 내부 HTTPS 자산만 접근할 수 있도록 차단.
- 저장 전에 중요한 원본은 반드시 백업하고, v0.1.35 안정 버전도 보관.

## 압축해제 폴더명 개선

- 동일 이름이 있으면 폴더명 (1), 폴더명 (2) 순으로 첫 빈 번호를 선택.
- 이미 존재하는 폴더·파일을 덮어쓰지 않고 대소문자 충돌도 검사.
- 해제 도중 다른 PC가 같은 폴더를 만들면 최대 10회 재검사하고 이름 변경.
- 기존 ZIP/7z/RAR 압축 해제 및 안전 제한은 그대로 유지.

## 검증 및 한계

- 로컬 크롬에서 rhwp 엔진 초기화 확인.
- 공개 테스트 문서 KTX.hwp 1쪽 로드와 HWP 직렬화 확인.
- 공개 테스트 문서 form-002.hwpx 10쪽 로드와 HWPX 직렬화 확인.
- XLSX 견본 B2 셀을 43으로 수정 후 재저장/재로드해 값 확인.
- Android 실기기 원본 저장·모바일 키보드·스크롤·서식 보존은 아직 미검증.
- 릴리스 전체 테스트·서명 결과는 프로젝트 작업일지에서 확인.
