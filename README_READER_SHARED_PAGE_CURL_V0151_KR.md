# NAS Mount Android v0.1.51
# EPUB / 만화책 / TXT 공통 종이책 넘김 애니메이션

## 무엇이 달라졌나요?

### EPUB
- 기존 2.5D Page Curl, 슬라이드, 페이드, 효과 없음 유지.
- 세 뷰어와 동일한 공통 책 넘김 효과 및 속도 설정을 사용.
- 비치는 뒷면 글자와 그림자를 약하게, 회전 가감속을
  자연스럽게 보정해 기존 기계적인 인상을 완화.
- 책갈피, 로딩 문구 제거, 일반 EPUB 본문 로딩은 이전과 동일.

### 만화책 (ZIP/CBZ/RAR/CBR/7Z/CB7)
- 기존 간단 슬라이드/페이드 코드를 교체하여 EPUB과 동일한
  Page Curl 렌더러를 사용.
- 화면에 실제로 보이던 만화 페이지를 가볍게 캡처하고, 다음
  압축 이미지가 풀린 뒤 위에서 종이 말림 효과를 재생.
- 한국식/일본식 읽는 방향에 맞춰 종이 넘김 좌우 방향을 반전.
- 폴드 펼침의 두 페이지, 좌우 합본 이미지 분할, 명암/밝기,
  확대, 책갈피, 다음 권 이어 읽기를 유지.
- 원본 압축파일은 그대로 두며 JPG/PNG 이미지 바이트 수정 없음.

### TXT 책
- 짧은 책, 대용량 TXT 모두 EPUB과 같은 종이책 효과 적용.
- 일반 페이지형: 기존 페이지의 화면을 캡처하고 다음 텍스트
  페이지를 표시한 뒤 선택한 넘김 효과를 실행.
- 대용량 TXT 페이지형: 새 48K 문자 구간의 페이지 계산이
  완료된 다음 종이 넘김을 시작해 로딩 중 화면 깜빡임을 완화.
- 폴드 펼침 두 쪽 레이아웃도 포함해 화면 전체에 동일 효과.
- 세로 연속 스크롤은 페이지가 아니라 지속 스크롤이므로
  책 넘김 애니메이션 없이 기존과 동일하게 움직입니다.
- 글꼴, 색, 줄간격, 책갈피, 독서 진행률 유지.

## 효과 및 설정

- 세 뷰어 어느 곳에서든 책보기 설정/Aa에서:
  1. 종이책 모서리 말림 (Page Curl) — 기본값
  2. 부드럽게 슬라이드
  3. 부드럽게 페이드
  4. 효과 없음
- 넘김 속도: 자연스럽게 / 천천히.
- EPUB, 만화책, TXT 설정은 앱 내부의 reader_shared_page_turn
  공통 설정으로 저장됩니다. 한 뷰어에서 변경하면 다른 뷰어를
  다음에 열 때에도 같은 설정을 적용합니다.
- 기존 EPUB v0.1.50 효과/속도 설정은 최초에 가져옵니다.

## 내부 변경과 안전성

- 신규 ReaderPageTransitions가 공통 화면 캡처와 애니메이션
  완료/취소, 중복 입력 방지를 담당합니다.
- 기존 EpubPageTurnOverlay와 EpubPageCapture를 재사용합니다.
  기기 화면의 가시 영역만 최대 1200×1900 픽셀로 캡처합니다.
- 화면 캡처에 실패하면 현재 페이지 넘기기는 중단하지 않고
  애니메이션만 생략합니다.
- 책을 닫거나 설정을 바꾸거나 폴드 화면이 바뀌면 진행 중인
  캡처/애니메이션을 안전하게 취소하도록 처리했습니다.
- EPUB/만화/TXT 소스 파일 자체와 NAS 연결 정보는 수정하지 않음.
- 새 v0.1.51 소스와 APK를 만들고 이전 버전은 보존했습니다.

## 검증 범위와 주의

- Android Gradle 컴파일, JUnit 자동 테스트, Android Lint,
  릴리스 빌드 및 서명·해시 검증 결과는 작업일지에 기록합니다.
- 실제 갤럭시 폴드 실기기에서 2.5D 애니메이션의 FPS·동작 감각,
  대용량 RAR 원격 해제 직후 애니메이션, 장 경계 전환 등의
  물리적인 시각 검증은 별도 필요합니다.
- 현재는 자동으로 종이가 넘어가는 2.5D 애니메이션이며,
  손가락으로 종이 모서리를 잡은 상태로 임의의 위치에서
  멈추는 실시간 3D 물리 메시 방식은 아닙니다.
