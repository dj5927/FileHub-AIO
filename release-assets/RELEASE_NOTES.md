## 추가된 기능
- 동영상 팝업 재생(PIP) 전환 버튼 및 예/아니오 선택
- 홈 버튼 자동 팝업 재생 켜기/끄기
- 팝업 내 시스템 재생/일시정지·닫기·전체화면 복귀 지원

## 수정 사항
- 팝업 재생 중 기존 영상과 자막·오디오 상태 유지
- 팝업에서 전체화면 복귀 시 재생 위치 유지
- 팝업에서도 이어보기 재생 위치 저장

## 기타 사항
- Android 기본 PIP를 사용하므로 팝업 크기와 크기 조절,
  닫기/전체화면 버튼 위치는 Android 시스템에서 관리
- 홈 버튼을 누른 후 앱이 별도 대화상자를 띄울 수 없으므로
  동영상 화면 팝업 버튼에서 먼저 선택한 뒤 홈 자동 전환 가능
