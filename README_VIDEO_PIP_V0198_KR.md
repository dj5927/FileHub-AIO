# FileHub AIO v0.1.98

## 추가된 기능
- 동영상 상단 팝업 버튼에서 팝업 재생 전환 예/아니오 선택
- 예: 재생 위치와 자막/오디오 상태를 유지한 채 Android PIP 전환
- 아니오: 팝업 없이 홈으로 나가기
- 플레이어 메뉴에서 홈 버튼 자동 팝업 켜기/끄기
- PIP 상태에서 시스템 제공 닫기, 전체화면 복귀, 재생/일시정지
- 영상 가로세로 비율에 맞는 PIP 크기 및 Android 시스템 리사이즈

## 수정 사항
- PIP 진입 시 기존 플레이어가 일시정지되지 않도록 변경
- 전체화면 복귀 시 기존 Media3 플레이어와 컨트롤 유지
- PIP 재생 중에도 이어보기 기록을 주기적으로 저장

## 기타 사항
- 시스템 홈 버튼을 앱이 가로채 예/아니오 대화상자를 표시할 수
  없으므로 플레이어 버튼에서 먼저 선택하도록 구성
- 동의 이후 홈 버튼을 눌러 나가면 자동 PIP로 전환
- 창 초기 크기, 핀치 크기 조절, 닫기/전체화면 버튼 위치는 Android
  시스템이 관리하며 별도의 다른 앱 위에 표시 권한은 불필요
- 실기기에서 PIP 크기 조절, 원격 재생, 앱 복귀 E2E 확인 필요
