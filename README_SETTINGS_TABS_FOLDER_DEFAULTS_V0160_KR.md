# NAS Mount Android v0.1.60 — 메인 설정 4개 탭, 기본값 + 폴더별 개별설정

## 요청과 설계

사용자는 메인 설정이 하나의 긴 스크롤 화면이고, 동영상/자막/코덱이
분리된 항목인 상태를 개선하도록 요청했습니다. 카테고리별 탭을
클릭하면 앵커 위치로 자동 스크롤하는 것이 아니라 해당 설정
페이지만 전환되도록 요청했습니다.

요청한 설정 우선순위:

1. 새 폴더/미지정 폴더는 메인 설정의 기본값을 사용.
2. 플레이어/책 뷰어에서 직접 수정한 항목은 해당 **폴더의 재정의값**을 사용.
3. 같은 만화 폴더의 1~10권, 같은 소설 폴더의 TXT/EPUB 각각,
   같은 동영상 폴더의 영상들은 타입에 맞는 재정의값을 공유.
4. 다른 폴더/다른 NAS 계정/다른 저장장치에는 영향을 주지 않음.
5. 기존 책갈피, 읽던 위치, 원격 연결, 미디어 원본을 변경하지 않음.

## 메인 설정 — 탭 전환

- 일반: 화면 테마, 현재 앱 정보. 향후 전역 기능 확장 가능.
- 동영상·자막: 영상 화면비율, 더블탭 이동 시간, 자막 크기,
  기본 자막 언어·소스, TTF 기본 글꼴, 자막·NFO 숨기기와
  동영상 폴더 규칙, 외부 코덱 폴더, 디코더 정보 및 라이선스.
- 만화책: 한국식/일본식 읽기 방향, 좌우 합본 분할 감도,
  폴드 두 페이지, 가로 폭 맞춤, 흑백, 명암·밝기,
  페이지 넘김 효과와 속도.
- 텍스트뷰어: TXT 별도 기본값(좌우 책 넘김/세로 스크롤,
  명조/고딕/고정폭, 글씨 크기·줄간격·여백·배경,
  폴드 두 페이지, 넘김 효과와 속도).
  같은 탭의 두 번째 구역에서 EPUB 기본값(읽기 모드,
  글자 크기·줄간격·여백·배경·넘김 효과·속도)을 독립 설정.

탭을 누르면 컨텐츠 화면 자체가 바뀝니다. 이전 구현의
인터페이스/동영상/자막/코덱/일반 5개 앵커 버튼과 전체
페이지 내 smoothScrollTo 동작은 더 이상 사용하지 않습니다.

## 폴더별 값 저장 방식

- FolderSettingsPolicy: 파일의 부모 디렉터리를 기준으로 범위를
  생성. 로컬 경로, SAF 문서 ID/SD·USB, 원격 계정 ID+경로를 구분.
- FolderMediaSettings: category + scope + 설정 항목으로 키를 분리.
  저장소는 별도의 SharedPreferences
  folder_reader_playback_overrides_v1 (SHA256 접두 키).
- 브라우저에서 실행한 경우 실제 현재 폴더 scope를 Intent로
  전달. 특히 일부 Android MediaStore·다운로드·SAF 문서 URI는
  파일 ID만 있어 부모 폴더를 추론하기 어려우므로 명시적
  scope가 우선 적용됩니다.
- 만화책 연속 다음 권 보기는 기존 Intent 복제 방식으로 같은
  부모 폴더 값을 유지합니다.
- 동영상 다음 편 연속 재생은 같은 folderScope Intent를
  다음 영상 Activity로 넘겨 설정을 그대로 사용합니다.
- 읽는 순간에는: 폴더별 값이 있으면 폴더값, 없으면 기존
  미디어 타입 전역 설정, 기존 전역 저장값도 없다면
  해당 앱에서 사용하던 원래 기본값을 사용합니다.
- 뷰어 설정창에서 **실제로 바꾼 항목만** 폴더별로 저장하며
  손대지 않은 속성은 이후 바뀐 전역 기본값을 계속 상속.
- 읽던 위치/책갈피/독서 진행률은 기존 파일 식별자 체계를
  그대로 사용하고, 폴더 스타일 설정으로 합치지 않습니다.

## 만화책

- ComicBookActivity: rtl, fit_width, contrast, brightness,
  grayscale, fold_two_pages, double_page_split, turn_effect,
  slow_page_turn을 폴더별로 저장.
- A만화/1권.zip에서 일본식으로 바꾸면 A만화/2~10권.zip도
  다음 열기부터 일본식. 다른 만화 디렉터리는 메인 기본값.
- 페이지 효과는 TXT/EPUB과 강제로 공유하지 않음.
- 만화책 보기 설정에 폴더 설정 초기화 버튼 추가.

## TXT

- BookTextActivity: font, size, spacing, margin, theme,
  view_mode, turn_effect, slow_page_turn, fold_columns을
  폴더별 재정의.
- 핀치 줌으로 변경한 폰트 크기도 같은 폴더의 설정으로 저장.
- 12만 자 이상 TXT의 빠른 첫 페이지 표시, 백그라운드
  전체 페이지 인덱스, 하단 줄누락 방지(v0.1.59) 유지.
- TXT 보기 설정에 폴더 설정 초기화 버튼 추가.

## EPUB

- EpubReaderActivity: mode, font_size, line_spacing, side_margin,
  theme, page_turn_effect, slow_page_turn을 폴더별 재정의.
- TXT와 EPUB은 모두 텍스트뷰어 탭에서 설정하되
  서로 다른 기본값과 서로 다른 폴더별 변경값을 가짐.
- EPUB 독서 설정에 폴더 설정 초기화 버튼 추가.
- 본문 페이지 누락 수정, 전체 빠른 이동 및 본문 분량 기준
  진행률(v0.1.56~0.1.58) 유지.

## 동영상 및 자막

- 메인 동영상·자막 탭의 값들은 전체 기본값으로 저장.
- VideoPlayerActivity는 폴더별 화면비율·더블탭 이동시간,
  자막 크기, 자막 소스, 자막 글꼴을 우선 참조.
- 재생 중 화면 맞춤/확대를 바꾸면 같은 영상 폴더의
  나머지 영상도 동일한 화면비율 사용.
- 자막 크기 변경은 **이 영상만**이 아닌 해당 폴더 전체 영상에
  저장. 추가한 자막 글꼴 메뉴에서 메인 기본 폰트,
  Android 시스템 글꼴 또는 등록한 폰트 중 선택 가능.
- 재생 중 자막 소스를 자동/내장/외부/끄기로 선택해도
  해당 폴더의 기본 선택 상태로 유지.
- 재생 설정 메뉴의 폴더 설정 초기화는 폴더별
  화면비율·자막 크기·소스·글꼴 등의 재정의를 제거.
- 과거 버전에서 저장한 영상별 자막 크기·소스는 데이터 손실을
  방지하기 위해 폴더 설정이 없는 경우의 레거시 대체값으로 유지.
  이후 새 폴더 설정을 저장하면 같은 폴더에서는 그 값이 우선.
  사용자가 명시적으로 기본값을 선택하면 해당 영상의
  기존 레거시 재정의는 함께 제거할 수 있습니다.

## 범위 제한과 수동 확인

- 구분 기준은 파일의 **직접 부모 폴더**입니다. 상위 폴더의
  속성을 모든 하위 폴더로 재귀 상속하도록 요청한 것은 아니므로
  A만화/1~10권처럼 동일 디렉터리에 있을 때만 자동 공유합니다.
- 내부 저장소, SD/USB, SAF, WebDAV/FTP/SFTP/SMB 및
  저장된 원격 연결에 대해 별도 scope를 구성합니다.
  opaque Content URI를 가진 외부 파일 열기에서는 폴더 정보가
  없으면 전체 기본값으로 돌아갈 수 있습니다.
- Android 컴파일/자동 JUnit/Android Lint/APK 서명/배포 SHA256
  검사는 작업일지 참조.
- 실제 갤럭시 폴드 USB/ADB 디바이스는 연결되지 않아
  앱 UI 4탭, 저장한 NAS 폴더 범위, SD·USB 탐색 및
  실제 미디어 재생 중 설정 전파는 기기에서 직접 클릭 검증 못함.
