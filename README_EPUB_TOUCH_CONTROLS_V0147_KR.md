# NAS Mount Android v0.1.47 — EPUB 터치 책 넘김 및 상하단 바 숨김

## 문제

- v0.1.46 EPUB은 스와이프로만 페이지를 넘길 수 있었습니다.
- 기존 EpubReaderActivity.onTouch는 65dp 이상의 좌우 이동만
  처리했고, 짧은 터치는 아무 작업도 하지 않았습니다.
- 만화책뷰어와 달리 EPUB에는 상단/하단 도구막대 숨김 함수가
  없어 본문을 최대 크기로 읽기 어려웠습니다.

## EPUB 수정 사항

- 일반 페이지 읽기에서 화면 왼쪽 약 30% 한 번 터치: 이전 페이지.
- 화면 오른쪽 약 30% 한 번 터치: 다음 페이지.
- 화면 가운데 약 40% 한 번 터치: 상단 제목/책갈피/Aa와
  하단 이전/다음/페이지 표시를 동시에 숨김 또는 다시 표시.
- 기존 좌/우 스와이프를 통한 페이지 이동 기능은 유지합니다.
- 세로 스크롤 모드에서도 왼쪽/오른쪽 터치는 한 화면 정도
  위/아래로 이동하며, 가운데 터치는 상하단 바를 숨깁니다.
- 실제 세로 스와이프는 WebView가 계속 정상 처리합니다.
- 짧은 단일 터치와 스와이프를 이동 거리/방향/시간으로 구분하여,
  드래그·긴 터치·두 손가락 터치는 책 넘김으로 오인하지 않습니다.
- 바 숨김 시 레이아웃 높이가 바뀌더라도 EPUB 장을 새로 로딩하지
  않고 기존 읽던 상대 위치를 복원하도록 보완했습니다.
- 폴드 펼침·접힘에서도 화면 폭에 비례하는 좌/중/우 터치 구역이
  자동 적용됩니다.

## 회귀 검증

- EpubTouchZonesTest에서 좌/중/우 짧은 터치, 좌/우 스와이프,
  세로 스크롤 모드, 긴 터치·두 손가락·세로 드래그
  오인 방지를 검증합니다.
- Android Gradle testDebugUnitTest, lintDebug, lintVitalRelease,
  assembleRelease 완료 여부는 작업일지에 기록합니다.
- EPUB 파일 파서/기존 v0.1.46 XML 오류 수정, 만화책·TXT 뷰어,
  원격 NAS 연결·책갈피·독서 진행도 로직은 변경하지 않았습니다.

## 남은 실기기 검증

- 개발 PC에 연결된 Galaxy Fold/Android 장비가 없다면
  실제 손가락 터치, 앱 바 숨김·다시 표시, EPUB 내부 링크 동작,
  폴드 펼침/접힘 중 페이지 위치 복원을 기기에서 확인해야 합니다.
- 지원되지 않는 DRM EPUB 기능은 이전 버전과 동일합니다.
