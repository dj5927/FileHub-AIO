# FileHub AIO Android v0.1.73 - QNAP 공유 폴더 자동 조회 및 복수 선택 (베타)

## 추가 내용

- NAS 공유 링크 설정에서 QNAP QTS·QuTS를 선택해도 **공유 폴더 목록 불러오기 · 여러 개 선택** 버튼이 나타납니다.
- File Station HTTP API의 `get_tree`, `node=share_root`로 해당 NAS 계정이 볼 수 있는 공유 폴더를 조회합니다.
- 여러 공유 폴더를 한꺼번에 체크해 저장합니다. 기존 Android 암호화 연결 저장소의 `nasShareRoots`를 이용하므로 연결 정보와 기존 Synology 설정은 유지됩니다.
- QNAP NAS 연결을 길게 눌러 **NAS 공유 폴더 탐색**을 열어, 선택한 폴더의 하위 항목을 표시하고 파일/폴더 공유 링크를 생성하도록 연결했습니다. 하위 파일 조회에는 `get_list`를 사용합니다.
- `NAS 공유 링크 관리`의 체크/일괄 해제 및 일반 파일 메뉴에서 생성만 표시하는 v0.1.72 변경은 그대로 유지됩니다.

## 설정 순서

1. NAS 공유 링크 설정 → QNAP QTS / QuTS 선택
2. **QNAP NAS 관리 HTTPS 주소**, **관리 계정**, **관리 비밀번호** 입력
3. **공유 폴더 목록 불러오기 · 여러 개 선택** → 필요한 공유 폴더 모두 체크
4. `선택 완료` → `인증 확인 후 저장`
5. 원격 저장소에서 QNAP 연결을 길게 눌러 NAS 공유 폴더 탐색 / 공유 링크 관리 이용

## 검증과 남은 일

- QNAP File Station API v5의 get_tree 공유 루트 응답(JSON 배열)을 파싱하는 테스트와 폴더 파일 목록, 복수 선택 허용 범위 검사 추가.
- Android 자동 빌드, JVM 테스트, Lint는 통과했으나 실제 QNAP 장비/계정은 연결되지 않았습니다. 따라서 펌웨어별 공유 폴더 조회, 2단계 인증, 하위 폴더, 실제 공유 링크 생성·해제의 종단간 확인이 필요합니다.
- QNAP QTS/QuTS의 펌웨어 버전과 File Station 권한에 따라 응답 형식 또는 API 동작이 달라질 수 있습니다.
- 서버 계정 비밀번호 및 인증 세션을 로그에 기록하지 않고 HTTPS 인증서 검증을 유지합니다.
