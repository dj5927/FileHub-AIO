## FileHub AIO Android v0.1.104 — 사진첩처럼 이어지는 부드러운 스와이프

- 일반 폴더에서 사진을 좌우로 넘길 때 손가락을 따라 현재 사진과 다음·이전 사진이 붙어서 이동합니다.
- 손을 놓으면 이동 거리와 속도에 따라 감속 애니메이션으로 자연스럽게 다음 사진으로 전환하거나 원위치로 돌아옵니다.
- 다음·이전 사진을 미리 불러오며, NAS에서 사진 다운로드가 아직 끝나지 않았다면 기존 사진을 검은색으로 지우지 않고 유지한 뒤 로딩 완료 시 전환합니다.
- 화면 터치 좌표를 고정된 실제 화면 기준으로 추적해 사진이 손가락에서 흔들리거나 되돌아오는 문제를 방지합니다.
- 사진의 가로세로 비율이 서로 다를 때도 전환 완료 프레임에서 맞춤 비율을 즉시 갱신합니다.
- 사진 확대·축소, 확대 후 드래그, 두 번 탭 확대 및 GIF 기능은 계속 지원합니다.
- 첫 사진·마지막 사진에서 빈 페이지로 이동하지 않으며 다른 폴더 사진과 혼합되지 않습니다.

- Android 단위 테스트 540개 중 실패/오류 0개(기존 선택 테스트 1개 제외), Lint 및 서명 Release APK 빌드 성공.
- 동일한 기존 앱 서명 유지, versionCode 105.
- 실제 Galaxy Fold 및 느린 WebDAV 사진 스와이프는 사용자 기기에서 추가 확인이 필요합니다.
