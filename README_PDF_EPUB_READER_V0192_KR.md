# FileHub AIO v0.1.92

## 수정 사항
- PDF도 기존 EPUB 책뷰어 화면으로 통합
- 로컬·SD/USB·NAS의 PDF 열기 경로를 EPUB 책뷰어로 연결
- 책 페이지 중앙 맞춤, 좌우 터치·스와이프, 책 넘김 효과·속도 지원
- 책갈피·전체 페이지 이동·읽던 위치 저장 및 Aa 독서 설정 지원
- PDF 확대 75~250%, 확대 중 화면 스크롤 유지

## 기타 사항
- PDF 원본 레이아웃은 그대로 유지(EPUB처럼 글자 크기를 바꾸는 리플로우는 지원하지 않음)
- 별도 PDF 화면은 제거하고 내부 PDF 페이지 렌더링만 파일 형식별로 처리
- 기존 EPUB/TXT/만화책 기능과 저장된 PDF 읽기 위치 유지
- 실기기에서 대용량 PDF와 페이지 넘김 효과의 동작 확인 필요
