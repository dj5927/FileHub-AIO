# FileHub AIO Android v0.1.101

- Gradle 9.9.1 / Android Gradle Plugin 9.5.0 빌드 체계 업데이트
- AndroidX Core, DocumentFile, OkHttp, SFTP(SSHJ), FTP(Commons Net) 최신 버전 반영
- ZXing QR 및 JSZip 3.10.2 업데이트, Office/HWP 리소스 검증
- Lifecycle, ExifInterface, Coroutines, Bouncy Castle 간접 라이브러리 업데이트
- 기존 Media3/NextLib 코덱 버전 및 앱 설정·스토리지 데이터 유지
- JVM 단위 테스트 528개 실행(실패 0개, 건너뜀 1개)
- 기존 v0.1.100과 동일한 정식 배포 서명 인증서 사용

참고: Android 기기별 NAS 로그인, 원격 파일 전송 및 코덱 재생은 실기기 확인이 필요합니다.
