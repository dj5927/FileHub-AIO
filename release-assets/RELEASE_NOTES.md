## FileHub AIO Android v0.1.103 — 일반 폴더 사진 좌우 스와이프

- 로컬·SD카드(SAF)·원격 일반 폴더에서 이미지를 연 뒤 왼쪽으로 밀어 다음 사진, 오른쪽으로 밀어 이전 사진으로 전환할 수 있습니다.
- 같은 폴더의 이미지만 현재 정렬 순서대로 탐색하고, 첫/마지막 사진에서 추가로 넘어가지 않습니다.
- 사진 확대·축소/확대 시 이동 및 더블탭 확대는 기존대로 유지되며 멀티터치는 사진 전환으로 처리하지 않습니다.
- 제목에 현재 사진 번호/전체 장수를 보여주며 GIF와 기존 이미지 형식을 지원합니다.
- 이전 사진을 읽는 네트워크 요청이 느린 경우 최신 사진 요청이 우선 표시되도록 캐시 로딩 동작을 개선했습니다.
- Android 536개 단위 테스트, Lint, 서명 Release 빌드 통과(선택적 테스트 1개 제외).
- 실제 Android 기기에서 로컬/SAF/WebDAV 사진 좌우 스와이프는 별도 사용자 환경에서 확인이 필요합니다.
