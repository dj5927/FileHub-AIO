# FileHub AIO Android v0.1.79 - 모든 설정 백업·가져오기 및 휴대폰 → TV 전체 설정 전송

## 어디에 있나요?

- FileHub AIO → 원격 저장소 목록 → 원격 저장소 추가 버튼 아래 **설정 파일 내보내기 · 가져오기**.
- 휴대폰 → 메뉴(⋮) → 휴대폰에서 TV로 계정 보내기 → TV QR 스캔/주소 입력 → **전체 설정 TV로 보내기**.
- Android TV → 홈 → 휴대폰에서 TV로 로그인 · QR 연결 → 일회용 QR 화면 → 수신 내용을 확인 후 병합 또는 전체 교체.

## 백업에 포함되는 것

- NAS SMB/FTP/SFTP/WebDAV, MYBOX, TeraBox 연결 주소·계정·비밀번호·NAS 공유 폴더 및 관리 설정(원래 연결 ID 유지).
- 즐겨찾기와 사용자 지정 별칭.
- 동영상·만화책·소설책 지정 폴더 목록, 숨김/제외 설정.
- 파일 목록 보기·정렬·썸네일, 테마·왼쪽 메뉴 펼침, 영상 기본/폴더별 설정 및 자막, 독서·페이지 넘김 설정, 기록/진행률.
- 백업 파일은 비밀번호 8~128자로 PBKDF2-HMAC-SHA256(210,000회) 및 AES-256-GCM으로 암호화. `.fhbackup` 확장자를 사용하며 비밀번호를 잃으면 복구할 수 없음.
- TV QR은 일회용 로컬 LAN AES-256-GCM 전송을 사용하고 원격 서버로 계정 정보를 업로드하지 않음. 전송할 대상 TV IP를 휴대폰에서 확인한 뒤 승인, 받는 TV에서도 병합/교체를 최종 승인.

## 파일로 이동하기

1. 휴대폰 원격 저장소 → **설정 파일 내보내기 · 가져오기** → 내보내기.
2. 백업 비밀번호 입력/재확인 후 Android 파일 저장소 선택기를 통해 `.fhbackup` 저장.
3. USB, NAS, 안전한 파일 전송 경로로 Android TV 또는 새 휴대폰에 전달.
4. 대상 기기 FileHub 원격 저장소 → **설정 파일 내보내기 · 가져오기** → 가져오기.
5. 백업 비밀번호 입력 후 파일 목록 미리보기 → 병합 또는 전체 교체 선택.

## QR로 바로 TV에 보내기

1. TV에서 FileHub QR 전송 시작. TV와 휴대폰은 동일 Wi-Fi에 연결.
2. 휴대폰에서 TV QR을 카메라로 스캔해 FileHub를 실행하거나 QR 텍스트를 휴대폰 메뉴에 붙여넣기.
3. **전체 설정 TV로 보내기**를 선택하고 TV 주소를 확인 후 전송 승인.
4. TV에서 받은 NAS 연결/즐겨찾기 수와 주의사항을 확인한 뒤 병합 또는 전체 교체를 선택.
5. 재실행해 설정을 반영하고 NAS 연결을 확인.

## 주의사항

- 원격 NAS 사용자 인증과 앱 설정은 옮길 수 있지만 **Android SD/USB Storage Access Framework URI 권한**, 미디어 접근 권한, 외부 코덱 파일과 코덱 디렉터리 접근 권한은 자동 이동하지 않습니다. 새 기기에서 다시 허용/선택해야 합니다.
- DSM 2단계 인증 신뢰 기기 ID는 다른 기기로 복사하지 않습니다. 필요하면 새 TV에서 인증을 다시 수행합니다.
- MYBOX PAT / TeraBox ndus 등 토큰은 백업 시점의 정보가 이전되며 유효기간이 지났다면 새로 갱신해야 합니다.
- 사용자 데이터(실제 동영상·책·자막 파일)는 백업에 들어가지 않습니다. 설정과 진행률만 옮깁니다.
- 병합은 동일 ID의 프로필을 업데이트하며, 신규 프로필을 추가합니다. 전체 교체는 앱 설정을 백업으로 교체하므로 기존 설정이 필요하면 먼저 별도 백업하세요.
- TV에서 파일 선택기 앱이 없는 경우 Android TV에서 `.fhbackup` 파일을 직접 선택할 수 없을 수 있으며, **QR 전체 설정 전송을 대안으로 사용**할 수 있습니다.
- LAN 전송은 QR 당 2분, 한 번의 전송, 최대 약 4MiB 데이터 제한. 너무 많은 시청 이력으로 제한을 넘으면 암호화 파일 백업/가져오기를 사용하세요.
- 별도 TV/휴대폰 실기기 ADB가 연결되지 않아 실제 파일 선택/QR TV 전송의 종단간 동작은 사용자 기기에서 검증해야 합니다.
