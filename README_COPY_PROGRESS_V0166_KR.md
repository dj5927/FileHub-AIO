# FileHub AIO Android v0.1.66 - 실시간 복사 진행률

- 기준 버전: v0.1.65, applicationId `com.nasmount.mobile` 유지, versionCode 67.
- 선택 파일 붙여넣기(복사/이동) 대화상자에 가로 게이지, 진행률(%), 전송된 용량/전체 용량, 현재 파일명, 완료 항목 수를 표시합니다.
- NAS -> 휴대전화, 로컬/SD 복사 과정의 실제 스트림 처리 바이트를 측정합니다. 원격 업로드는 업로드 입력 스트림이 읽힌 바이트를 측정하므로 서버의 최종 저장 확정 전에는 99%까지만 표시합니다.
- 복수 파일과 폴더는 선택 전체 크기를 계산해 총량 기준으로 표시합니다. 원격 폴더 크기 계산은 메타데이터 조회가 필요해 전송 준비가 다소 길어질 수 있습니다.
- 서버 내부 복사/이동, 동일 드라이브 이름 변경은 실제 네트워크 다운로드 바이트가 없어 완료 시 항목 기준으로 갱신합니다.
- 파일 크기가 알려지지 않은 경우에는 진행바를 회전형으로 표시하고 `--%`, 전송된 용량 및 `전체 용량 확인 불가`를 보여줍니다. 불명확한 총용량에서 가짜 퍼센트를 표시하지 않습니다.
- 기존 덮어쓰기 확인과 실패 처리, 저장 후 미디어 갤러리 등록을 유지합니다.
- 자동 테스트에는 160 KiB 두 파일 복사의 진행률 단조 증가/전체 합계/복제 내용 검사와 용량 표시 테스트가 포함됩니다.
- 자동 테스트는 Android 실제 장치의 네트워크 업로드·쓰기 성능 및 UI 육안 검증을 대체하지 않습니다. Galaxy Fold 실기기에서 실제 NAS 파일 복사 후 확인이 필요합니다.
