# NAS Mount Android v0.1.43 — 폴더 용도 통합 / 책 폴더 설정창 수정

## 증상 및 원인

- 이전 버전에서 '독서용 폴더 지정'을 실행하면 긴 설명과 '취소'만
  보이고 실제 '만화책'/'텍스트책' 선택지가 나오지 않았습니다.
- Android AlertDialog.Builder에서 setMessage()와 setItems()를
  함께 사용하면 메시지 레이아웃이 선택 목록을 대체할 수 있습니다.
- 폴더를 길게 눌러 선택 상태로 바뀌면 상단 도구막대 ⋮가
  선택 도구막대로 바뀌기 때문에 설정할 수 있는 메뉴를 찾기 어려웠습니다.

## 수정 사항

1. 폴더를 길게 눌러 하나 선택합니다.
2. **하단 더 보기 → 폴더 용도 설정**을 누릅니다.
3. **동영상 폴더 설정/해제** 또는
   **독서용 폴더 설정/해제**를 선택합니다.
4. 독서용 폴더에서는 **만화책 폴더 지정/해제**,
   **텍스트책 폴더 지정/해제**를 목록으로 보여주며
   실제 항목을 눌러 저장할 수 있습니다.
5. 설정한 뒤 선택 상태를 종료하고 현재 폴더 목록을 갱신합니다.
   원래 폴더는 이동하거나 수정하지 않습니다.

상단 ⋮로 현재 폴더를 설정하는 경우에도 폴더 용도 설정 메뉴로
통일했습니다. SD카드·NAS·클라우드·내장 저장소에 동일하게 적용됩니다.
선택할 때는 실제 폴더를 한 개만 선택해야 합니다.

## 폴더 목록 라벨

- 상위 폴더 목록에서 직접 지정한 폴더를 표시합니다.
  - 파란 배경 소형 배지 **동영상폴더**
  - 초록 배경 소형 배지 **독서용폴더**
- 예시: 122개 항목 [동영상폴더].
- 동영상/독서용을 동시에 설정했다면 두 배지를 모두 표시합니다.
- 목록/자세히 보기에서는 항목 수 옆, 격자 보기에서는
  좁은 화면을 고려해 항목 수 아래에 표시합니다.
- 목록의 날짜, 폴더 열기, 기존 자막 배지, 항목 수 계산은 유지합니다.
- 부모에게서 기능이 상속된 하위 폴더에는 중복 배지를 표시하지 않습니다.
  별도로 지정한 경우에만 표시하며, 하위 폴더에서도 실제 기능은 상속됩니다.
- 동영상 폴더 규칙은 기존 PlayerSettings의 자막 숨김 설정을 그대로
  사용하며 과거 설정을 삭제하거나 마이그레이션하지 않습니다.
- 독서용 폴더 규칙도 기존 ReaderFolders 저장소를 그대로 사용하므로
  v0.1.42에서 등록한 항목을 유지합니다.

## 테스트 / 제한

- Windows Android Gradle 컴파일, JUnit, Android Lint, release 빌드 및
  APK 서명/배포 해시 검증 결과는 프로젝트 작업일지에 기록합니다.
- FolderPurposePolicyTest는 로컬·NAS·SAF 폴더별 명시적 설정의 배지
  표시, 중복 폴더명·계정 분리, 부모 설정 상속 시 배지 중복 방지 등을
  검증합니다.
- 실제 Galaxy Fold 휴대폰을 연결해 화면을 누르며 확인할 수 있는
  테스트 장비는 현재 연결되지 않았습니다.
- 만화책/텍스트책 뷰어 자체의 대용량·RAR·폰트 렌더링 등은
  이번 UI 변경과 별개로 여전히 실기기 확인이 필요합니다.
