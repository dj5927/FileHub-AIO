# NAS Mount Android v0.1.48 — EPUB 장 전환 안내 숨김 / 대용량 책 지원

## 문제 원인과 수정

1. EPUB에서 다른 장으로 넘어갈 때마다 중앙에 "본문을 표시하는 중..."
   안내가 번쩍이며 나타났습니다.
   - 원인: EpubReaderActivity.openChapter()가 매 장 로딩 때
     상태 라벨을 Visible로 강제 변경.
   - 수정: 최초 책 열기 중에만 상태 안내를 보이고, 이후 장 전환은
     안내를 숨긴 상태로 조용히 진행. 본문 읽기 오류는 계속 표시.
   - 좌우 페이지 터치/스와이프, 가운데 메뉴 숨기기, 책갈피 유지.

2. 12MB보다 큰 TXT 소설은 열 수 없었습니다.
   - 원인: ReaderSource.MAX_TEXT=12MB 및 BookTextCodec.load의
     입력 바이트 상한.
   - 수정: TXT 독서에서 해당 고정 크기 제한을 제거했습니다.
   - 소설 파일을 백그라운드에서 스트림으로 읽어 앱 캐시에
     UTF-16 인덱싱 파일로 변환합니다. 중간에 책 전체를 메모리에
     올리지 않습니다.
   - 작은 TXT는 기존 전체 메모리 뷰어로 연결하고, 큰 TXT는
     디스크에서 필요한 24,000자(스크롤) / 48,000자(페이지 계산)
     구간만 읽어 본문을 표시합니다.
   - 기존 페이지형 / 세로 연속 스크롤형을 모두 지원합니다.
   - 큰 TXT도 읽던 위치, 책갈피(진행률 기준), 전체 읽기 %를
     앱 내부에 저장합니다. 스크롤 위치는 장치 변경 후 복원됩니다.
   - 대용량 MS949/EUC-KR 한글 TXT, UTF-8, UTF-16 BOM 감지를 유지.
   - 기존 파일 자체는 변경하지 않습니다.

3. EPUB은 책 원본의 전체 512MB 상한을 제거했습니다.
   - EPUB은 ZIP 압축 파일을 직접 검색하고 필요한 장만 읽습니다.
   - NAS/클라우드/SD카드 파일은 임시 캐시에 받아서 읽습니다.
   - 전체 EPUB 크기에 대한 임의의 고정 상한은 적용하지 않습니다.
   - 단, 보안을 위해 개별 EPUB 본문, 리소스, XML 파싱,
     ZIP 압축 해제 크기 검사는 유지합니다.

## 중요한 제한 및 실기기 확인

- '전체 파일 크기 고정 제한 없음'은 무제한 메모리/저장소를 뜻하지
  않습니다. 매우 큰 TXT/원격 EPUB은 단말기 캐시에 여유 공간이
  있어야 하며, 파일 내용이 많을수록 처음 여는 시간도 늘어납니다.
- EPUB의 단일 XHTML 장은 4MB, 이미지/CSS 등 단일 리소스는
  24MB 제한이 기존처럼 유지되어 있습니다. 압축 폭탄 방지용입니다.
- 소설 TXT가 수십/수백 MB일 때의 페이지 계산은 큰 TXT 모드에서
  부분 페이지 목록으로 표시하므로 전체 예상 쪽수 대신 읽은 %
  중심으로 표시합니다.
- 큰 TXT 스크롤에서 구간 경계에 진입하면 현재 위치를 기준으로
  디스크에서 다음 구간을 로드합니다.
- 코드 빌드/단위 테스트/Android Lint/APK 서명은 작업일지에 기록.
- 실제 갤럭시 폴드에서 대용량 원격 EPUB 및 TXT를 직접 조작하는
  검증은 별도입니다. 12MB가 넘는 TXT의 파일 기반 읽기 테스트와
  MS949 한글/줄바꿈 검증을 자동화했습니다.
- 기존 v0.1.47 설치 데이터, NAS 프로필, 만화책/책갈피 설정 보존.
