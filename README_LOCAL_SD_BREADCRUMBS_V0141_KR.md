# NAS Mount Android v0.1.41 - 내장 저장소와 SD카드 경로 이동 통일

## 개선 사항

- 기존 네트워크 폴더의 클릭 가능한 경로 버튼(빵부스러기 탐색)을
  **내장 저장소와 SD카드**에도 동일하게 적용했습니다.
- 기존 로컬 폴더 상단의 /storage/emulated/0/... 경로 텍스트를
  가로 스크롤되는 경로 버튼으로 교체했습니다.
- 예: 홈(⌂) > 1.예능 > 어서와 한국은 처음이지 시즌2
- 상위 폴더 버튼을 누르면 즉시 해당 폴더로 이동합니다.
- 긴 경로는 오른쪽 끝 현재 폴더가 자동으로 보이고, 사용자가
  가로 스크롤하여 상위 경로를 선택할 수 있습니다.
- SD카드 직접 접근 경로(/storage/UUID/...)는 SD카드 최상위까지만
  버튼을 구성하며 저장소 밖으로 이동하지 않습니다.
- SD카드 SAF 방식은 사용자가 실제로 접근 허용한 폴더가
  최상위 버튼이며, 허가 범위 바깥으로 탐색하지 않습니다.
- 기존 네트워크 폴더 경로 버튼의 색상, 크기, 터치 영역,
  가로 스크롤 동작을 공유하도록 구현했습니다.
- 기존 NAS 연결/즐겨찾기/미디어/문서/SD 권한 데이터는 변경하지 않습니다.

## 검증

- StorageBreadcrumbsTest: 내장 저장소, 최상위, SD카드,
  유사 접두사 경로, 경로 이탈 방지, SAF 폴더 상대 경로를 검증합니다.
- 첫 테스트에서 Windows JVM의 POSIX 경로 해석 차이를 발견하여
  절대 경로 세그먼트를 플랫폼 독립적으로 정규화하도록 수정했습니다.
- Android JUnit, lint, release 빌드와 APK 서명 결과는 작업일지에 기록합니다.
- 개발 PC에 연결된 실기기가 없어 실제 폴드 화면 터치/스크롤
  동작은 테스트 사용자 기기에서 최종 확인이 필요합니다.
