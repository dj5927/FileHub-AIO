# NAS Mount Android v0.1.42 — 내장 만화책·텍스트책 뷰어

## 사용 전 — 폴더 지정

1. NAS Mount에서 **만화책으로 볼 압축파일이 들어 있는 폴더**로 이동.
2. 우측 상단 **⋮ → 독서용 폴더 지정/해제 → 만화책 폴더 지정**.
3. 다른 폴더에서 동일하게 **텍스트책 폴더 지정** 선택.
4. 지정된 폴더와 **모든 하위 폴더**에서만 해당 뷰어가 자동 실행됩니다.
5. 메뉴에서 다시 누르면 해당 폴더의 지정만 해제됩니다.

지정은 로컬 내장 저장소, 권한을 허용한 SD카드 폴더(SAF 포함),
원격 NAS/WebDAV/FTP/SFTP/SMB 및 연결된 클라우드 계정의
각 폴더별로 독립적으로 저장됩니다.

지정된 폴더 외에는 기존 동작 그대로입니다.
- 일반 ZIP/RAR/7Z → 기존 압축해제 및 압축 작업
- 일반 TXT → 기존 텍스트 편집
- CBZ/CBR/CB7 → 각각 ZIP/RAR/7Z 압축파일로 인식
- 만화책 폴더에서는 TXT는 원래 기능, 텍스트책 폴더에서는
  ZIP/RAR/7Z는 원래 기능을 사용합니다.
- 폴더 자체를 변경하거나 실제 파일을 이동하지 않습니다.

## 만화책 뷰어

- ZIP/CBZ, RAR/CBR, 7Z/CB7 안의 JPG/JPEG/PNG/WEBP/BMP/GIF 파일을
  자연스러운 숫자 순서로 정렬하여 한 장씩 보여줍니다.
- 압축파일 전체를 **풀지 않고** 특정 페이지 이미지만 캐시합니다.
  원격 아카이브의 압축 원본은 네트워크에서 앱 임시 캐시로
  한 번 다운로드할 수 있습니다(내용 전체 추출은 하지 않음).
- 한 손가락 좌우 스와이프 및 화면 좌/우 터치로 이전/다음 페이지.
- 한국식(왼쪽 스와이프 다음) / 일본식(오른쪽 스와이프 다음) 전환.
- 두 손가락 1~6배 확대, 드래그 이동, 더블탭 확대/원래 크기.
- 전체 화면 맞춤과 가로 폭 맞춤(세로로 긴 페이지는 드래그 이동).
- 명암 대비 50~200%, 밝기 -100~100, 흑백 모드.
- 페이지 번호/전체 페이지, 진행 슬라이더, 읽던 페이지 자동 저장,
  가운데 탭 시 도구 숨김/표시.
- 압축 원본은 수정하지 않습니다. 이미지 페이지만 임시 파일로 읽음.

현재 한계:
- 압축파일 최대 1.5GB, 이미지 한 페이지 압축 해제 최대 48MB,
  페이지 이미지 최대 4096px로 샘플링하여 메모리 사용량 제한.
- 암호화/암호 보호된 RAR은 미지원. 특수 RAR 버전, 분할 압축,
  JPEG2000/AVIF/HEIC 압축 페이지는 미지원할 수 있습니다.
- GIF는 만화책 안에서는 첫 장면을 정지 이미지로 표시합니다.
- 원격 만화책은 페이지별 서버 랜덤 접근이 아니라 압축파일을
  우선 앱 캐시에 받아 읽으므로 큰 책은 첫 로딩이 오래 걸릴 수 있습니다.
- 좌우 두 페이지 펼침, 웹툰 연속 세로 모드는 아직 미지원.

## 텍스트책 뷰어

- TXT 본문을 **실제 화면 폭, 글꼴 크기와 줄간격 기준으로 측정**하여
  페이지 단위로 나눕니다. 단순 글자 수 기준으로 분할하지 않습니다.
- UTF-8(및 BOM), UTF-16 LE/BE, 한국어 MS949(구형 텍스트) 처리.
- 명조/고딕/고정폭 글꼴, 글씨 크기 12~38sp, 줄간격 1.0~2.4배,
  좌우 여백 9~44dp.
- 아이보리 종이/흰색/세피아/야간 어두운 테마.
- 좌우 스와이프 또는 좌/우 화면 터치로 페이지 넘김.
- 두 손가락으로 본문 글씨 확대/축소, 읽던 문자 위치 자동 복원.
- 글씨 설정·회전·전체 화면 전환 후에도 읽던 위치 기준 재페이지 계산.
- 전체 페이지/퍼센트/슬라이더 표시, 가운데 터치로 상하 도구 숨김.

현재 한계:
- TXT 최대 12MB, 이미지/표가 들어 있는 EPUB/PDF/DOCX는
  이번 텍스트책 뷰어 대상이 아닙니다.
- 텍스트책은 **읽기 전용**. 내용 수정은 폴더 지정을 해제한 후
  기존 내장 텍스트 편집기로 합니다.

## 개발 참고 및 라이선스

- 참고: ComicSparks/jasmine은 Flutter+Rust, README상 상업적
  이용 제한 명시. **Jasmine 소스/이미지/자산을 이 앱에 복사하지 않음.**
- 참고: Mihon(Apache-2.0), Bubble2(GPL-3.0).
- 앱 구현은 자체 Java UI와 이미 포함된 Apache Commons Compress,
  junrar, Android 기본 이미지/텍스트 렌더러로 구축.
- 새로운 네이티브 다운로드 엔진/외부 뷰어 앱/외부 편집 서버 없음.
- 원본 책 파일/클라우드 경로는 읽기 전용; 독서 진행 설정은
  기기 내부 앱 설정에 저장합니다.

## 테스트

- 자동 테스트: 폴더 지정 범위/계정 분리, ZIP 및 7Z 단일 페이지 추출,
  숫자 페이지 정렬, 잘못된 압축 경로 차단, UTF-8/UTF-16/MS949
  문서 해독, 페이지 위치 탐색.
- Android Gradle JUnit, lintDebug, lintVitalRelease, assembleRelease 결과는
  릴리스 작업일지에 기록합니다.
- Android 실기기가 연결되지 않은 경우 실제 폴드 터치, RAR/클라우드
  파일 네트워크 대역폭/랜덤 액세스, 큰 TXT의 줄바꿈 성능은
  별도 기기 검증이 필요합니다.
