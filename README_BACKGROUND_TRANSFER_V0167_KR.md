# FileHub AIO Android v0.1.67 - 백그라운드 파일 복사·이동

기준 버전은 v0.1.66입니다. 앱 패키지, 서명, 사용자 계정 데이터는 변경하지 않습니다.

## 사용

1. 파일 복사 또는 이동 후 붙여넣기를 누르면 기존 진행률 창에 **숨기기 / 취소** 버튼이 표시됩니다.
2. 숨기기를 누르면 진행률 창이 닫히고 탐색기 오른쪽 상단에 작은 `35%` 표시가 남습니다. 이 표시를 누르면 진행창이 다시 열립니다.
3. 전송 중에도 파일 탐색, 다른 문서/동영상 보기, 설정 사용 등이 가능합니다. 추가 복사·이동·붙여넣기는 한 전송이 종료될 때까지 차단됩니다.
4. 홈 버튼으로 앱을 벗어나도 `dataSync` 포그라운드 서비스가 전송합니다. Android 알림바에 파일명, 진행률, 전송 용량, 취소 동작이 표시됩니다. 알림을 누르면 앱의 진행창을 엽니다.
5. Android 13 이상에서는 복사·이동 시작 시 알림 권한을 허용해야 진행할 수 있습니다.

## 안전 및 제한

- 취소 시 활성 스레드를 중단하고 현재 입력 스트림을 닫아 중단을 시도합니다. 완료된 파일은 유지되며 로컬/SD의 실패 중 파일은 기존 정리 로직이 처리합니다. 원격 제공자의 부분 업로드 임시 파일 제거는 해당 서버 구현에 좌우됩니다.
- 서버 측 복사·이동은 파일 데이터가 앱을 통과하지 않으므로 %가 완료 시에만 갱신될 수 있습니다.
- 앱 프로세스가 운영체제에 의해 강제 종료되면 전송을 이어서 재개하는 기능은 포함하지 않습니다. Android 15 이상 `dataSync` 서비스에는 운영체제 실행시간 제한도 적용됩니다.
- 별도 서비스 스레드에서 작업하므로 메인 파일 탐색기 스레드는 복사 때문에 차단되지 않습니다.
- 미니 진행률 표시는 FileHub의 메인 탐색 화면에만 나타납니다. 다른 앱에서의 진행률은 알림바를 이용하세요.
- Android 기기 접근이 없어 빌드·JVM 자동 테스트와 실제 삼성 휴대전화 알림 UI 테스트는 구분해야 합니다.
