# FileHub AIO Android v0.1.103 — 일반 폴더 이미지 좌우 스와이프

## 기능

- 일반 로컬 폴더, SD카드(SAF) 폴더, 연결된 원격 폴더의
  이미지를 한 장 열면 같은 폴더에 있는 모든 이미지 파일을
  기존 파일 정렬 순서대로 이전/다음 사진으로 넘깁니다.
- 화면 왼쪽으로 밀기: 다음 사진, 오른쪽으로 밀기: 이전 사진.
  첫 사진/마지막 사진에서 반대쪽으로 넘어가지 않습니다.
- 이미지 제목에 현재 사진 번호/전체 장수를 표시합니다.
- 두 손가락 확대·축소, 확대된 사진 한 손가락 이동,
  두 번 탭 확대/복귀를 기존처럼 유지합니다. 확대 중의
  가로 이동이나 두 손가락 동작은 사진 넘기기로 해석하지 않습니다.
- JPG/JPEG/PNG/WEBP/BMP/GIF/HEIC/HEIF의 기존
  지원 범위만 사진 목록에 포함합니다. 비이미지/하위 폴더는
  제외하고 숨김 표시 설정도 따릅니다.
- 대용량 폴더에서도 목록을 매번 네트워크 재조회하지 않습니다.
  폴더 화면이 이미 가지고 있는 전체 목록(화면 표시 페이징보다
  많아도 전체)을 프로세스 내부에 저장하고 뷰어에는 작은
  목록 식별자만 전달하므로 Intent 데이터 크기 한도를 넘기지 않습니다.
- 사진을 바꿀 때 비동기 요청 번호를 검사하여 오래된 사진
  로딩 완료가 뒤늦게 현재 사진을 덮어쓰지 않도록 했습니다.
  이전 캐시 파일도 바뀐 뒤 정리합니다.
- 폴더가 아닌 전체 '이미지' 미디어 탭이나 다른 앱에서
  직접 열 때는 기존 단일 사진 뷰어 동작을 유지합니다.
- 앱 프로세스가 종료되어 메모리 내 목록 정보가 없어진
  경우에도 현재 단일 이미지 열기는 정상적으로 유지됩니다.

## 검증

- ImageFolderSequenceTest: 폴더 내 이미지 필터링, 순서,
  맨 처음/맨 끝 경계, 다른 경로/다른 원격 프로필 차단,
  숨김 사진 처리.
- ImageSwipePolicyTest: 좌/우 판별, 세로 스크롤과 짧은
  동작 무시, 확대/핀치 동작 중 넘김 금지.
- 실제 삼성 Fold/Android 기기에서 특히 1장 폴더,
  다량 사진 폴더, 원격 느린 서버 및 GIF를 열어 확인하세요.
