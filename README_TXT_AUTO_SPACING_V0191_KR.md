# FileHub AIO v0.1.91

## 추가된 기능
- TXT 책의 비정상적인 빈 줄을 자동 감지해 독서 화면에서만 정리
- 문장 사이 공백은 줄이고, 문단 구분용 빈 줄은 유지

## 수정 사항
- 기존 책갈피·읽던 위치를 원본 글자 위치 기준으로 유지
- 대용량 TXT도 파일 기반으로 정리해 화면 멈춤 방지

## 기타 사항
- 기본으로 자동 적용, 일반 TXT 문서는 변경하지 않음
- 원본 TXT 파일 자체는 절대로 수정하지 않음
- EPUB·PDF·만화책에는 적용하지 않음
- 자동 감지는 보수적으로 동작: 패턴이 명확하지 않으면 원본 그대로 표시
