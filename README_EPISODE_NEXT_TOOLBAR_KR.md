# NAS Mount Android v0.1.29 — 폴더 영상 연속재생 및 상단 아이콘 개선

## 기준 및 버전

- v0.1.28의 기능을 유지한 독립 소스 복제판
- versionCode 30, versionName 0.1.29
- PC용 NAS Mount 소스/베타는 건드리지 않음

## 1. 상단바 아이콘 중앙 정렬

- 기존 메뉴(글꼴 ☰), 홈(글꼴 ⌂), 즐겨찾기(글꼴 ☆/★),
  검색(시스템 이미지), 보기(글꼴 ☷), 더보기(글꼴 ⋮)의 서로 다른
  폰트 베이스라인·패딩으로 인한 시각적 수직 어긋남을 제거.
- 새 ToolbarIconView.java로 모든 버튼의 24×24dp 자체 제작
  벡터 도안을 단일 좌표계에 중앙 배치하고, 터치 영역은 동일하게 40dp.
- 메뉴 / 홈 / 별표 / 새로고침 / 검색 / 보기 / 더보기 순서로 정렬.
- 즐겨찾기 여부는 별표의 비어있는 모양/노란색 채워진 모양으로 즉시 표시.
- 기존 화면 제목 및 선택 작업바, Fold7 펼침 레이아웃 유지.

## 2. 영상 폴더에서 이전·다음 파일 전환

- 로컬 / SD카드 SAF / NAS 원격 저장소(WebDAV, SMB, FTP, SFTP,
  TeraBox, MYBOX 등) 파일 목록에서 같은 폴더의 영상만 모아 재생 목록 구성.
- 기기 미디어 영상 탭에서 열었을 경우에는 Android 10+의
  MediaStore RELATIVE_PATH로 실제 동일 폴더끼리만 목록 구성.
  Android 9 이하의 전체 미디어 검색 화면은 폴더 식별 불가 시
  잘못된 다른 폴더로 넘어가지 않도록 기존 단일 재생.
- 현재 파일관리자의 정렬이 수정일/크기여도 재생 목록에서는
  숫자가 포함된 파일명을 자연스럽게 정렬 (01, 02, 03, ... 10, 11).
  영상 파일만 포함하며 자막 .srt/.smi, .nfo 등은 제외.
- Media3 기본 재생기는 단일 MediaItem일 때 이전·다음 버튼을
  비활성화하므로, 기존 exo_prev/exo_next 위치의 시각적 버튼을
  동일한 이미지/레이아웃으로 교체하고 앱 고유 재생 목록으로 연결.
- 이전 편/다음 편이 존재할 때만 해당 버튼 활성화.
  누르면 해당 파일의 원격 데이터 소스, 동영상 자막 탐색, 해상도/화면 회전,
  영상별 이어보기 설정을 새로 준비해 재생.
- 영상이 끝나면 **'다음 편을 재생할까요?'** 확인창을 표시.
  '다음 편 재생'을 누르면 다음 영상으로 이동, '아니요'를 누르면
  종료된 상태로 유지. 마지막 영상은 확인창을 표시하지 않음.
- 너무 큰 폴더에서는 Intent 크기 초과를 막기 위해
  현재 영상 기준 최대 120개 영상만 전환 가능하도록 제한.
  필요하면 파일관리자에서 다음 범위의 영상을 직접 실행.

## 3. 새로고침 버튼

- 파일관리자 상단바 별표 바로 오른쪽에 원형 화살표 새로고침 아이콘 추가.
- 네트워크 폴더에서는 기존 세션 목록 캐시를 명시적으로 비운 후
  서버 폴더 목록과 상태를 새로 요청.
- 내부 저장소/SAF 폴더에서는 즉시 새 목록을 읽고 폴더 개수 캐시 갱신.
- 미디어 탭에서도 새로 검색하도록 연결.
- 일반 폴더 이동이나 화면 스크롤 시에는 기존 캐시 정책 유지.

  :app:assembleRelease --offline --no-daemon --max-workers=2` 성공.

## 주의

- 실제 Galaxy Fold7 / 일반 Android 스마트폰에서 다음·이전 컨트롤의
  표시 위치, 컨트롤 자동 숨김 및 자동 다음 편 확인창은 실기기 검증 필요.
- Android 동영상 재생은 각 편마다 새로운 PlayerActivity로 전환하며,
  다음 편의 이어보기 이력이 있다면 해당 편의 이어보기 선택창이
  추가로 표시될 수 있음.
- TeraBox ndus 기반 웹 쓰기 API는 비공식이고 실계정 테스트 별도 필요.
- NextLib FFmpeg GPLv3 배포 의무 및 기존 PC WebDAV LOCK 베타 테스트
  대기 상태는 이전 버전과 동일.
