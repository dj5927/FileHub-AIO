# FileHub AIO v0.1.88

## 추가된 기능
- 같은 내부망에서 TV QR 표시 → 휴대폰 앱 내 카메라 스캔 → 암호화 설정 전송

## 수정 사항
- 인터넷 QR 중계 서버 주소 입력·외부망 QR 기능 제거
- 책이 수백·수천 권인 폴더의 목록 조회와 정렬을 백그라운드로 이동
- 로컬·SD·NAS 파일 목록을 화면당 60개씩 순차 표시
- 소설책·만화책·동영상 지정 폴더의 긴 목록도 60개씩 표시
- 업데이트 안내를 추가된 기능·수정 사항·기타 사항만 짧게 표시

## 기타 사항
- 기존 LAN 자동 기기 검색 전송과 파일 백업·복원 유지
- QR은 같은 내부망에서만 동작하며 별도 서버나 주소 입력이 필요하지 않음
- 설정 수신 후 받는 기기에서 병합 또는 전체 교체 승인 필요
- Android package com.nasmount.mobile / versionName 0.1.88 / versionCode 89

## 사용 방법
1. 받는 TV: 원격 저장소 → 설정 파일 내보내기·가져오기 → LAN QR 전송 → QR 표시·받기
2. 보내는 휴대폰: 같은 메뉴 → QR로 전송하기
3. 앱 내 카메라가 열리면 TV QR을 비춰 인식 → 설정 자동 암호화 전송
4. TV에서 병합 또는 전체 교체를 선택하면 복원

휴대폰과 TV가 같은 Wi-Fi/LAN에 있고 공유기 클라이언트 격리 설정이 꺼져 있어야 합니다.
QR은 2분간 유효합니다. 권한 승인, 화면 방향 등은 기기 모델마다 다를 수 있어
실제 휴대폰/TV에서 QR 스캔과 책 대량 목록 스크롤을 한 번 점검해야 합니다.
