# NAS Mount Android v0.1.40 - SD카드 권한줄 숨김 / 즐겨찾기 별칭

## SD 저장소 화면 개선

- v0.1.39는 SD카드 전체 접근 권한이 이미 허용되어 카드 파일
  목록이 표시되어도 상단에 'SD카드 접근 권한 변경' 버튼을
  무조건 노출했습니다.
- v0.1.40은 전체 접근(로컬 직접 경로)과 저장된 하위 폴더
  SAF 접근 화면에서 이 상단 버튼을 제거합니다.
- 다시 권한을 설정하고 싶을 때는 SD카드의 오른쪽 위
  더보기(⋮) → 'SD카드 접근 권한 설정'을 선택하면 됩니다.
- 권한이 없는 상태에서 SD 저장소를 선택하면 기존처럼
  시스템 권한 허용 및 SD 하위 폴더 선택을 안내합니다.

## 즐겨찾기 표시 이름 변경

- 실제 원본 폴더명과 별개로 즐겨찾기 표시 이름(alias)을 저장합니다.
- 예: 원본 폴더 02영화 → 표시 이름 영화모음집.
  큰 글씨 '영화모음집' 아래 10sp 작은 글씨로 '02영화'를 표시합니다.
- 홈 즐겨찾기, 전체 즐겨찾기, 왼쪽 탐색 메뉴에 동일하게 표시됩니다.
- 항목 오른쪽 ⋮ 또는 길게 누르기를 통해
  '즐겨찾기 이름 변경' 및 '즐겨찾기 삭제'를 선택합니다.
- 새로 즐겨찾기 등록하면 별칭 입력창이 나타납니다.
  취소해도 즐겨찾기 등록은 유지됩니다.
- '원래 이름'을 누르면 별칭을 초기화합니다.
- 이름 제한: 최대 80자, 줄바꿈/제어문자 불가.
- 실제 폴더 경로/원본 이름/연결 ID/즐겨찾기 식별 키는 변경하지 않습니다.
- 기존 버전의 즐겨찾기 JSON은 별칭 필드가 없어도 기존
  이름으로 정상 표시되며 업데이트 시 데이터를 잃지 않습니다.
