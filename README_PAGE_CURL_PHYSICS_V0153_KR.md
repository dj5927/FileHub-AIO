# NAS Mount Android v0.1.53 — 높이에 따라 다른 종이 접힘과 이전 페이지 애니메이션 개선

## 수정 이유

v0.1.52의 실시간 Page Curl에서 손가락을 페이지 상단·중간·하단
어디에 두더라도 항상 아래쪽 접힘이 먼저 움직이는 현상이 있었습니다.
기존 EpubTurnGeometry.topEdge/bottomEdge는 아래쪽을 먼저 이동시키고
위쪽을 16% 지연시키는 고정 규칙이었습니다. 또한 이전 페이지로
돌아갈 때 현재 페이지를 왼쪽에서 오른쪽으로 벗겨내기만 하고,
실제로 돌아와야 할 이전 장을 종이처럼 다시 펼쳐 덮지 않아
방향과 반사된 뒷면이 어색했습니다.

## v0.1.53 변경

### 손가락 위치에 따른 탄성 접힘

- 페이지 아래쪽을 잡아 끌면 아래 모서리부터 크게 접힙니다.
  중간과 위쪽은 탄성이 있는 종이처럼 점진적으로 따라옵니다.
- 페이지 위쪽을 잡으면 위 모서리가 먼저 접히고 아래가 뒤따릅니다.
- 페이지 가운데를 잡으면 위아래 끝의 움직임이 대칭이며,
  가운데 접힘이 먼저 진행됩니다.
- 손가락을 위아래 대각선 방향으로 이동시키면 접히는 중심도
  함께 이동하고 종이 접힘선이 자연스러운 곡선으로 변합니다.
- 화면을 16개 높이 구간으로 분할해 여러 점을 잇는 곡선으로
  모서리를 표현합니다. 위아래만 움직이는 사다리꼴 접힘이
  아니라, 가운데 영역도 탄성 있게 반응합니다.
- 손가락을 도로 가져오면 접힘이 되돌아가며, 완전히 놓으면
  기존 43% 기준으로 이전 페이지 복귀 또는 넘김 완료를 결정합니다.
- 접힌 종이 뒷면의 폭도 잡은 지점 근처에서 가장 두껍고,
  떨어진 위치에서는 좁게 보이도록 보정했습니다.
- 페이지 진행도 0%와 100%에서는 종이의 모든 높이에서
  접힘선이 동일하게 시작/완료되며, 중간 접힘선이 갑자기
  역방향으로 움직이지 않도록 모델을 수정했습니다.

### 이전 페이지 모션 좌우 반전

- 다음 페이지: 오른쪽 페이지를 들어 왼쪽으로 걷어냅니다.
- 이전 페이지: 기존 페이지 전체를 배경에 두고 실제 이전 페이지의
  화면 이미지를 새로 캡처하여 왼쪽에서 오른쪽으로 펼칩니다.
- 이전 페이지의 접힘선, 종이 뒷면, 그림자도 새 방향에 맞춰
  좌우 대칭이 되도록 변경했습니다. 단순히 기존 장을 좌우로
  밀어내던 방식보다 실제 책장을 되돌리는 느낌에 가깝습니다.
- EPUB은 WebView가 이전 XHTML 장을 표시한 뒤 해당 화면을
  캡처합니다. 만화책은 압축파일에서 이전 이미지 디코딩 후,
  TXT는 이전 페이지 조판 후 캡처합니다.
- 이전 장을 열었다가 드래그를 취소하면 원래 장과 읽던 위치를
  복원하는 기존 동작을 유지합니다.

### 기존 기능과 적용 범위

- EPUB, TXT 페이지형, 만화책 모두 공통 EpubPageTurnOverlay 및
  ReaderPageTransitions를 사용하여 같은 접힘 모델 적용.
- 만화책은 실제 화면에 표시된 이미지 경계에 맞춰 종이 효과 적용.
- 만화책의 일본식 RTL 방향도 해당 독서 방향에 맞춰 반전.
- 폴드 펼침 두 페이지, 만화책 합본 분할, EPUB 가운데 터치
  UI 숨김, 책갈피, 진행률, 대용량 TXT 구간 읽기 유지.
- 세로 연속 스크롤에는 Page Curl이 적용되지 않음.
- 짧은 터치 자동 넘김과 기존 슬라이드/페이드/효과 없음 유지.
- PageCurlPhysicsTest 8개에서 손잡이 위치, 중앙 대칭, 대각선
  이동, 이전 페이지 좌우 반전, 시작/종료 수렴, 진행도
  단조 증가 및 되돌림을 검증.

## 기술적 한계 및 실기기 QA

- 종이의 부드러움과 그라데이션은 Android Canvas 기반
  2.5D 근사 모델입니다. 물리 엔진의 진짜 3D 종이 메시나
  화면 접점마다 변하는 텍스처 굴절까지 구현한 것은 아닙니다.
- 실제 갤럭시 폴드에서의 손가락 추적 프레임률, 이전 페이지
  Bitmap 캡처 시점, 느린 NAS 압축파일의 로딩 체감, 회전과
  화면 접힘 전환은 연결된 안드로이드 장비가 없어 직접 검증할
  수 없습니다. 실기기 확인이 필요한 베타 버전입니다.
- 기존 소스·APK, 설치 데이터, 책갈피, NAS 설정은 보존됩니다.
- 테스트/빌드/배포/백업 내역은 작업일지.md에 기록했습니다.
