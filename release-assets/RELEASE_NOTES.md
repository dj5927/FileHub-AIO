## 수정 사항
- 팝업을 X로 닫으면 영상과 소리를 완전히 종료하도록 수정
- 기존 팝업 종료 전 새 영상 재생 시 중복 소리가 나오던 문제 수정
- 팝업 재생을 시작하려고 미리 눌러야 했던 버튼 제거

## 추가된 기능
- 재생 중 홈 버튼으로 나가면 즉시 팝업 진입 후 계속/정지 선택
- 최초 한 번 '다른 앱 위에 표시' 권한 허용 시 홈 화면에서 예/아니오 확인창 제공
- 팝업 터치 시 10초 뒤로, 재생/일시정지, 10초 앞으로 컨트롤 표시

## 기타 사항
- 특별 권한 미허용 시 PIP 자체의 계속 재생/종료 버튼으로 선택
- 팝업 크기와 닫기/전체화면 버튼은 Android 시스템에서 관리
