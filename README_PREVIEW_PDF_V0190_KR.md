# FileHub AIO v0.1.90

## 추가된 기능
- 메인 설정의 TXT·EPUB 기본값에 예시 문단 실시간 미리보기 추가
- 만화책 기본값에 예시 그림 실시간 밝기·명암·흑백 미리보기 추가
- 메인 설정의 수치·선택형 대화창에서 적용 전 미리보기 제공
- PDF 책 뷰어 추가: 로컬·SD/USB·NAS 파일 열기, 페이지 이동, 확대, 읽던 위치 저장

## 수정 사항
- 설정 취소 시 미리보기 변경값이 저장되지 않도록 분리
- PDF는 원본 페이지 배치를 유지해 표시하고 큰 페이지는 제한된 메모리에서 렌더링
- 독서 뷰어 메뉴에 PDF 지원 안내 추가

## 기타 사항
- 기존 폴더별 설정과 TXT·EPUB·만화책의 저장 값 유지
- PDF는 Android 기본 PdfRenderer 사용, 암호 PDF는 지원하지 않을 수 있음
- Android 8.0 이상 설치 지원(minSdk 26)
- PDF 렌더링·저장 복원 실기기 검증은 별도로 필요
