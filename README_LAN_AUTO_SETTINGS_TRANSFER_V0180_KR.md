# FileHub AIO v0.1.80 - 동일 네트워크 설정 자동 전송

## 사용법 (QR이나 백업 파일 이동 불필요)

1. **TV**: FileHub → 원격 저장소 → `설정 파일 내보내기 · 가져오기` → `같은 네트워크에서 설정 가져오기 (자동 수신)`을 누릅니다.
2. **휴대폰**: 같은 버전 FileHub → 원격 저장소 → `설정 파일 내보내기 · 가져오기` → `같은 네트워크로 설정 내보내기 (자동 전송)`을 누릅니다.
3. 휴대폰이 같은 LAN의 FileHub 수신 대기를 자동으로 찾습니다. 발견 기기가 하나라면 해당 기기의 **이름과 사설 IP**를 보여주고, 여러 대라면 목록에서 기기를 선택합니다.
4. **휴대폰에서 대상 기기 확인 1회**: NAS 비밀번호와 클라우드 세션이 포함될 수 있어 사용자가 자신이 소유한 기기로 보내는 것을 확인해야 합니다. 확인 후 다른 주소나 코드 입력 없이 암호화 전송합니다.
5. TV에서는 수신 완료 뒤 가져올 설정의 연결 수·즐겨찾기 수를 확인하고 **병합** 또는 **전체 교체**를 선택합니다. 기존 설정의 보존은 병합을 권장합니다.

## 특징

- UDP 포트 38427로 동일 LAN의 수신 대기 FileHub 자동 발견. IPv4 LAN 브로드캐스트/방송 주소 사용. 응답은 수신자가 연 임시 TCP 포트를 알려줍니다.
- 수신 대기는 2분 뒤 자동 종료. 설정 검색은 같은 시간 범위에서 자동 재검색합니다. 취소 버튼으로 즉시 중지 가능합니다.
- 전송용 난수 챌린지, 매번 새 EC P-256 임시키(ECDH)로 AES-256-GCM 키를 파생. 민감한 설정의 평문은 장치 밖으로 나오지 않습니다. 검색 자체는 인증된 기기 확인이 아니므로 보내는 측에 최종 대상 확인 UI가 있습니다.
- TV가 복원 승인하기 전에는 암호화된 계정 정보가 영구 저장되지 않습니다. 수신은 한 번 완료하면 자동 종료됩니다.
- 같은 Wi-Fi이더라도 게스트망 또는 공유기의 AP/클라이언트 격리, VPN, 방화벽 등의 영향으로 자동 검색이나 연결이 차단될 수 있습니다.
- NAS/WebDAV/FTP/SFTP/MYBOX/TeraBox 연결, 즐겨찾기, 동영상·만화책·소설책 콘텐츠 폴더, 파일 보기·자막·재생·독서 설정을 전달합니다. **실제 영상/책 파일 자체는 복사하지 않습니다.**
- Android SD/USB 폴더에 대한 시스템 접근 허용, 외부 코덱 파일은 다른 기기에 자동 전달되지 않으므로 새 기기에서 다시 선택하세요.

## 다른 이동 방법도 유지

- `설정 파일로 저장 (.fhbackup)`: 별도 비밀번호로 암호화한 백업 파일 생성. USB, NAS, 파일 공유 등을 통해 다른 기기로 직접 이동할 수 있습니다.
- `설정 파일 불러오기`: 받은 .fhbackup 파일을 비밀번호로 열고 병합 또는 교체합니다.
- `TV로 계정 전송 (기존 QR)`: 이전 v0.1.79의 QR 페어링도 계속 사용할 수 있습니다.

## 검증 범위

- 프로젝트 자동 단위 테스트, Android Lint, 정식 서명 APK 빌드 후 배포합니다.
- 개발 환경에 ADB 연결 기기가 없어 **휴대폰과 TV 간 LAN 검색·전송의 실기기 종단간 검증은 아직 필요**합니다.
