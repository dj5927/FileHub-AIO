# NAS Mount Android v0.1.37 - Word / PowerPoint 내장 뷰어와 컴팩트 화면

## 새 기능

- DOCX Word: NAS Mount 내부 WebView에서 docx-preview 0.4.1
  (Apache-2.0)을 이용해 Word 문서를 보여줍니다. 화면 맞춤 기본,
  100% 보기 전환, 문단 선택 후 텍스트 수정 기능을 제공합니다.
- 저장 시 JSZip 3.10.1(MIT/GPL 선택)을 사용하여 선택 문단의
  텍스트만 기존 DOCX ZIP 패키지에서 변경하고 나머지 XML과
  이미지/표 등을 가능한 한 보존합니다.
- PPTX PowerPoint: pptx-browser 4.1.5(MIT)의 오프라인 Canvas
  뷰어, 이전/다음 슬라이드 이동, 텍스트 상자 선택·수정,
  PPTX 재저장 기능을 제공합니다. 외부 오피스 앱을 호출하지 않습니다.
- 오래된 DOC / PPT 바이너리는 현재 내장 파서가 없습니다.
  잘못된 파일로 덮어쓰지 않도록 DOCX/PPTX 변환이 필요하다고 안내합니다.

## 화면 면적 개선

- Android 파일명 상단 52dp에서 38dp로 축소.
- 파일 로딩 후 앱의 두 번째 상태 안내줄 제거, 작업 메시지는 잠깐
  나타나는 오버레이로 변경.
- HWP 리본과 자는 기본 접힘. 플로팅 도구 버튼으로 펼칠 수 있습니다.
- Excel 기본 시트 선택 37px, 수식 입력 38px의 가느다란 두 줄로 축소.
  이동 버튼과 도움말은 기본 숨김. 플로팅 더 보기 버튼으로 다시 펼침.
- 저장 버튼 아래쪽 높이를 약 44px로 축소.
- Word 기본 전체 페이지 화면 너비 맞춤, 100% 확대 버튼 추가.
- PPTX 슬라이드를 사용 가능한 화면 폭에 맞게 표시.

## 한계 및 안전

- Word 문단 수정은 텍스트 중심입니다. 선택 문단 안의 글자별
  서식 일부가 통합될 수 있습니다.
- PowerPoint는 텍스트 상자 수정 중심입니다. 고급 애니메이션,
  SmartArt, 차트, 글자별 복잡한 서식의 완벽한 보존은 미보장입니다.
- Excel 수식 재계산/피벗/매크로/고급 서식은 여전히 미구현입니다.
- 기존 내장 HWP/HWPX 엔진을 유지하며 폰트 대체 문제가 있을 수 있습니다.
- 64MiB 문서 크기 제한. NASMount 기존 원본 덮어쓰기 방식 재사용.
  중요한 원본 문서는 백업한 뒤 테스트해야 합니다.
- 문서 자격 증명은 Android Java 계층에 두고 오프라인 로컬
  WebView 자산만 사용합니다. 외부 편집 서버/폰트 사이트를 호출하지 않습니다.

## 개발 검증

- python-docx 테스트 DOCX에서 문단 수정 후 재생성한 DOCX XML에
  수정 내용이 포함되며 다른 문단은 유지됨을 Chrome에서 확인.
- python-pptx 2장 PPTX에서 슬라이드 표시와 텍스트 상자 수정,
  저장된 PPTX XML에 변경 내용 포함을 Chrome에서 확인.
- 430x920 기준 Excel 셀 도구줄 37px, 그리드 높이 701px,
  HWP 리본 숨김 및 문서 편집 영역 높이 716px 확인.
- Android 전체 빌드/단위 테스트/서명 결과는 작업일지에 별도 기록.
- 삼성 폴드 실기기에서의 터치, DOCX/PPTX 복잡 서식과 네이버/테라박스
  원본 저장은 아직 직접 검증하지 못했습니다.
