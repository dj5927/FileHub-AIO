# FileHub AIO PC v1.3.82 - Excel 저장 / 파일 잠금 개선 시험판

## 변경 사항
- v1.3.81 기반. 연결 프로필, 기존 설정 경로, 백업/복원 기능을 유지합니다.
- WebDAV, SFTP, FTP 협력 잠금에서 불필요한 NASMount_사용중_...xlsx 상태 파일의 신규 생성을 제거했습니다.
- 기존 협력 잠금은 .nasmount.lock 디렉터리를 계속 사용합니다. 앱에서 숨기더라도 타사 탐색기에서는 보입니다.
- 저장 후 원격 잠금 해제에 일시적 네트워크 오류가 발생하면, 업로드가 안전한 상태인지 재확인하면서 재시도하도록 변경했습니다. 다른 사용자 잠금을 임의 삭제하지 않습니다.
- WinFsp Excel 임시 파일의 추가 이름 패턴 및 원본 파일명 대소문자를 보존합니다. 11월매출.xlsx의 .XLSX 변경 경로를 회귀 검사했습니다.
- WebDAV 서버 기본 잠금(LOCK/UNLOCK, 원격 sidecar 없음)에서 Excel의 8자리 임시 백업 파일 이름도 처리합니다.
- 환경 설정에 "WebDAV 서버 LOCK 지원 검사" 바로가기를 추가했습니다.

## 서버에 잠금 폴더를 남기지 않는 방법
1. 중요 문서는 먼저 별도로 백업하고, 다른 PC에서 편집하는 사용자가 없는지 확인합니다.
2. 연결 목록에서 WebDAV 프로필을 선택합니다.
3. 환경 설정 -> WebDAV 서버 LOCK 지원 검사로 임시 파일의 LOCK/UNLOCK, 쓰기 차단 및 정리 지원을 확인합니다.
4. 검사가 성공한 서버에서, 연결을 해제한 다음 그 WebDAV 프로필의 설정에서 "서버 기본 잠금 (폴더 없음)"을 명시적으로 켭니다.
5. 운영 문서 대신 테스트용 .xlsx에서 Excel 열기/수정/저장/닫기와 두 PC 접근을 먼저 확인합니다.
6. 해당 서버의 LOCK 지원이 미흡하면 기본 잠금 모드로 되돌릴 수 있으나, 그 경우 물리적 .nasmount.lock 폴더는 계속 사용합니다.

## 제한 및 주의
- v1.3.82는 실제 사용자 NAS에서 모든 Excel 저장/파일 잠금 시나리오를 검증한 정식 해결판이 아니라 시험판입니다.
- 기존 NAS에 남은 NASMount_사용중_...xlsx 또는 .nasmount.lock 파일/폴더는 자동 삭제하지 않습니다. 다른 PC에서 편집 중일 수 있으므로 소유자/사용 중 여부를 확인한 뒤 정리해야 합니다.
- 구버전과 새 서버 표준 잠금 모드가 혼재하면 서로 잠금 상태를 인식하지 못할 수 있습니다. 동일 NAS 문서를 구버전/신버전으로 동시에 편집하지 마세요.
- 서버 기본 잠금은 WebDAV RFC4918 LOCK/UNLOCK을 실제 지원해야 하며, 미지원 시 안전을 위해 Excel 쓰기를 차단할 수 있습니다.
- 일부 Excel 저장 경고는 NAS의 수정 시간/ETag, WebDAV 캐시, 다른 프로그램의 파일 갱신과 관련될 수 있습니다. 실제 NAS에서 재현되면 클라이언트 로그와 서버 응답으로 추가 원인을 확인해야 합니다.
- 사용 중인 .nasmount.lock 폴더를 일괄 삭제하거나 숨기는 것만으로 다른 프로그램의 동시 쓰기가 안전해지지는 않습니다.

## 로컬 검증
- 두 프로젝트 Windows Release 빌드 성공.
- Excel COM + 로컬 NTFS + WinFsp 가상 드라이브에서 11월매출.xlsx를 열고 두 번 연속 저장. 파일명 대소문자 및 두 번째 내용 유지 통과.
- WinFsp 잠금 콜백/0바이트 덮어쓰기 차단/원본 파일명 회귀 검사 통과.
- 원격 UNLOCK이 처음 두 번 실패한 상황의 재시도 회복 검사 통과.
- 모의 NAS + 실제 rclone WebDAV 업로드 경유 잠금, 두 연결 충돌, 임시 파일 백업, 한국어 이름 및 sidecar 0건 검사 통과.
- 실제 사용자 NAS에서의 서버 LOCK 검증과 Excel 다중 PC 동시 편집 검증은 완료되지 않았습니다.

## 실행
- 기존 v1.3.81에서 모든 Excel 문서를 저장하고 열려 있는 문서/업로드가 없을 때 안전하게 종료합니다.
- 새 배포 ZIP을 별도 폴더에 압축 해제하고 FileHubAIO.exe를 실행합니다.
- tools 폴더의 rclone.exe, rclone-terabox.exe, NASMountLockBridge.exe 및 WinFsp 구성 요소를 제거하지 마세요.
