# NAS Mount v1.3.75 — 일괄 연결 표시 및 Google 초기화 진단

## RaiDrive 비교에서 확인한 부분

- RaiDrive의 네트워크 드라이브는 목록 전체가 준비된 뒤 탐색기 표시가 한 번에 갱신되는 것처럼 관찰되었습니다. 이는 **사용자가 관측한 동작**이며 비공개 소스의 실제 내부 구현이 확인된 것은 아닙니다.
- NAS Mount v1.3.74는 드라이브마다 Windows에 도착 알림과 전체 아이콘 갱신 요청을 반복하여 바탕화면이 여러 번 깜빡일 수 있었습니다.
- 실제 v1.3.74 기록에서는 연결 6개 완료가 빠를 때 7.58초, 느릴 때 35.28초였습니다. 느린 사례의 Google Drive는 rclone 초기화 약 35초, 실제 드라이브 폴더·용량 확인 243ms였습니다. 따라서 폴더 캐시 확대만으로는 35초 지연이 해결된다고 단정할 수 없습니다.

## 이번 수정

1. 모든 rclone, WinFsp 마운트와 파일잠금은 **기존처럼 독립적·병렬로 시작**합니다.
2. 자동 연결 묶음에서는 개별 Windows 볼륨 도착 알림을 바로 여러 번 발송하지 않고, 검증 완료된 드라이브 문자를 보관합니다.
3. 모든 연결 시도가 끝나면 650ms 동안 레이블 등록을 안정화한 뒤, **검증된 드라이브들의 문자 비트마스크를 하나로 합쳐 WM_DEVICECHANGE를 한 번만 전송**하고, 내 PC 폴더도 한 번 갱신합니다.
4. Google Drive처럼 오래 걸리는 연결은 모든 드라이브의 표시를 차단하지 않도록 최대 9초 대기 제한을 적용합니다. 이후 늦게 연결되는 Google Drive만 별도로 표시하므로, 상황에 따라 알림이 1~2회 발생할 수 있습니다.
5. 이미 연결을 해제했거나 다른 프로그램 소유로 확인된 문자는 묶음 알림에서 제외합니다. 탐색기 프로세스 강제 재시작, 캐시 삭제, 강제 마운트 종료는 수행하지 않습니다.
6. Windows 및 WinFsp 자체에서 별도 드라이브 추가 이벤트가 발생할 수 있으므로 화면 깜빡임이 0회가 된다고 보장하지 않습니다.

## Google Drive 초기화 진단

- **환경 설정 → Google 연결 초기화 진단** 체크 후 다음 Google Drive 연결부터 적용됩니다. 기본값은 꺼짐입니다.
- rclone DEBUG 출력을 직접 로그에 쓰지 않습니다. 비밀정보·파일명·URL을 제외하고 정해진 분류 이름과 경과시간만 기록합니다.
- 로그 구분: `GOOGLE_STARTUP_DIAG` + `process_started`, `backend_creation`, `oauth_refresh`, `rate_limit`, `api_retry_or_pacer`, `mount_setup`, `root_discovery`, `drive_letter_ready` 등.
- 정밀 진단은 Google 계정 토큰·비밀번호를 변경하지 않으며 API 제한을 우회하지도 않습니다.
- 공용 OAuth Client ID 대신 본인 Client ID를 사용하려면 **드라이브를 안전하게 연결 해제 → Google Drive 행의 ··· 메뉴 → Google 계정 재인증 → 개인 Client ID/Client Secret 입력 후 Google 브라우저 승인**을 직접 진행해야 합니다. 기존 토큰을 다른 Client ID에 그대로 옮기면 안 됩니다.
- 새로 인증하기 전에 기존 연결과 모든 업로드를 끝내세요. Google 자체 API 속도와 OAuth 정책은 외부 서비스에서 결정되며 재인증이 2~3초 연결을 보장하지 않습니다.

## 유지한 기능

- rclone 공식 v1.76.0, TeraBox rclone-extra v1.76.0-extra, NASMountLockBridge v1.3.73 변경 없음.
- 기존 v1.3.73의 Excel 파일명 대소문자 보존, 0바이트 저장 차단, 파일 잠금, 안전한 업로드 및 드라이브 해제 기능 유지.
- NAS와 클라우드의 실사용 데이터·계정·비밀번호를 개발/자동 테스트에 사용하지 않았습니다. 실제 연결 속도·깜빡임은 사용자 PC에서 확인이 필요합니다.

## 설치 안내

1. 기존 연결에서 파일 전송을 완료하고 Excel 문서를 닫은 후 안전하게 연결 해제합니다.
2. `NASMount_1_3_75_BATCH_SHELL_FULL.zip` 전체를 새로운 폴더에 압축 해제합니다. 기존 버전의 실행 중인 파일을 덮어쓰지 마세요.
3. NASMount.exe를 실행합니다. `tools` 폴더의 rclone, 잠금 브리지 DLL, .sha256 파일은 반드시 함께 유지합니다.
4. NAS Mount 전체 연결이 완료되기까지 걸린 시간, 바탕화면 깜빡임 횟수, Google Drive 접속시간을 비교합니다. 반복 지연이면 설정의 Google 진단을 켜서 새로 연결한 뒤 안전한 분류 로그를 비교합니다.
