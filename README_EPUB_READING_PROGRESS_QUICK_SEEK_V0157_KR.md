# NAS Mount Android v0.1.57 — EPUB 진행률 보정 + 0~100% 빠른 이동

## 사용자 제보와 원인

EPUB 본문 전체를 읽을 수 있도록 v0.1.56에서 페이지 누락을 수정했지만,
하단에 51 / 54장 · 93%처럼 표시되는 값이 실제 책 전체 분량과
맞지 않음. 또한 하단 장수·퍼센트를 탭해 좌우 수평 슬라이더로
빠른 이동하는 기능 요청.

기존 EpubReaderActivity의 진행률은 chapterIndex*10000+fraction을
chapters.size()*10000으로 나누었습니다. 즉 분량이 매우 짧은
목차와 아주 긴 본문 챕터를 같은 크기로 취급하여, 54개 중
51번째 챕터에 있다는 사실만으로 약 93%가 표시됐습니다.

51 / 54장은 EPUB 내부 XHTML 파일(장) 번호이며 전체 책 페이지
수가 아닙니다. 폰트·화면 크기에 따라 실제 표시 페이지는 변합니다.

## 본문 글자량 기반 새 진행률

- EpubArchive.readingWeights()는 각 XHTML의 본문 텍스트에서
  head/style/script/nav/svg와 태그, 불필요한 공백을 정리한 후
  실제 표시되는 글자량을 챕터별로 측정합니다.
- 이 작업량을 통제하기 위해 XHTML 전체 분량이 64 MiB를 넘으면
  압축 해제 이전 ZIP 항목의 원래 바이트 크기를 이용해 추정합니다.
  파싱에 실패한 개별 장에서도 동일한 바이트 크기를 사용합니다.
- EpubProgressMap은 본문 분량이 많은 챕터에 더 큰 비중을
  부여해 책 전체 0~100%의 추정 진행률을 산출합니다.
- 기존 ReadingHistory 저장 위치와 책갈피의
  chapterIndex*10000+0..9999 형식은 그대로 유지합니다.
- EPUB을 열고 레이아웃이 준비되면 이전 방식으로 저장됐던
  퍼센트를 새 방식으로 다시 저장해 파일 목록의 표시도 갱신.
- 책갈피 목록의 퍼센트도 EPUB에서는 새 본문 비중으로 표시.
  TXT/만화책의 기존 진행률 계산은 변경하지 않음.

## 하단 화면 표시

- 예시: 51/54장 · 3/12쪽 · 약 87%
- 51/54장 = 현재 챕터 번호 / 전체 챕터 수.
- 3/12쪽 = 현재 챕터의 페이지(또는 폴드 두 페이지 묶음) 위치.
- 약 87% = 책 전체 본문 글자량 기준 추정 진행률.
- 폴드 접힘/펼침, 글꼴 크기 및 여백 변경에 따라 챕터 내
  페이지 수는 변하지만 전체 분량 계산의 기준은 유지합니다.
- 세로 연속 스크롤 모드에서는 현재 챕터 쪽수 표기를 생략합니다.

## 페이지 정보 터치 → 책 전체 빠른 이동

- EPUB 화면 하단 중앙의 페이지·퍼센트를 누르면
  EPUB 전체 빠른 이동 대화상자가 열립니다.
- 좌우 슬라이더로 전체 책의 0.0~100.0%를 0.1% 단위로 탐색.
- 손가락을 움직이는 동안 선택 위치의 예상 퍼센트 및 장 번호 표시.
- 이동 버튼을 누르면 해당 장/챕터 내부 위치에서 독서를 재개.
  취소 버튼은 기존 읽던 페이지를 유지합니다.
- 렌더링 중이나 페이지 Curl 애니메이션 중에는 충돌 방지를 위해
  선택을 제한합니다.
- 기존 EPUB 페이지 누락 수정, 레이아웃 완료 검증,
  책갈피와 이전 읽던 위치 복원 처리 기능을 유지합니다.

## 검증 범위 및 주의사항

- EpubProgressMapTest: 짧고 긴 챕터 가중치, 0/100 끝점,
  0~100% 이동의 단조 증가, 비정상 입력 방어, 레거시 기록 유지.
- EpubArchiveTest: 실제 EPUB ZIP fixture의 본문 글자 수로 계산,
  HTML 태그/스타일/메타데이터가 진행률에 섞이지 않는지 확인.
- Android Java 컴파일, 전체 단위 테스트, Android Lint,
  릴리스 서명/버전 확인, 배포본 SHA256 검증은 작업일지에 기록.
- 본문 글자량 기준 진행률은 실제 인쇄 페이지 수를 전부 미리
  렌더링한 정밀한 실물 책 퍼센트가 아닌 추정값입니다.
  특히 삽화가 많은 도서는 실제 페이지 수와 차이가 날 수 있습니다.
- 실기기 갤럭시 폴드가 ADB에 연결되지 않아 터치 영역,
  슬라이더 조작감 및 모든 EPUB 유형은 직접 검증하지 못했습니다.
