# NAS Mount Android v0.1.50 — EPUB 종이책 페이지 컬 효과

## 새 기능

- EPUB 독서 화면 → Aa → EPUB 독서 설정 → "책 넘김 효과 (페이지형)"
  에서 종이책 모서리 말림(Page Curl), 부드럽게 슬라이드,
  페이드, 효과 없음 중 선택 가능.
- 속도: 자연스럽게 / 천천히 선택 가능.
- 기본값: 종이책 모서리 말림 효과, 약 540ms.
- EPUB 좌우 터치, 좌우 스와이프, 하단 이전·다음 버튼에서
  선택한 애니메이션을 적용합니다.
- 종이책 넘김은 현재 페이지의 화면 이미지를 임시 캡처하고
  다음 페이지를 먼저 그린 다음, 위에 올라간 기존 페이지의
  아래쪽 모서리가 먼저 들리며 곡선으로 말리도록 표현합니다.
- 종이 뒷면의 반사 이미지, 종이색과 음영, 움직이는
  접힌 선과 그림자를 사용합니다. 원본 EPUB의 본문은 손대지 않습니다.
- 다음 장으로 넘어갈 때는 이전 장 캡처 화면을 유지한 상태로
  다음 XHTML을 불러오고, 준비된 화면 위에 넘김 효과를 실행합니다.
- 화면 캡처는 Android PixelCopy (minSdk 26)를 먼저 사용하고,
  미지원/실패 시 WebView.draw(Canvas)로 대체합니다.
- 캡처 화면은 최대 1200×1900픽셀 수준으로 제한하고, 효과 종료
  즉시 메모리에서 해제합니다. 느린 장치에서도 페이지 전환이
  멈추지 않도록 캡처 실패 시 효과를 생략하고 정상 페이지로 이동합니다.
- 애니메이션 중 중복 입력을 막아 장/페이지가 한 번에
  여러 번 건너뛰는 현상을 예방합니다.
- EPUB 연속 세로 스크롤 모드는 종이 넘김 효과를 적용하지
  않고 기존 부드러운 세로 스크롤을 유지합니다.
- EPUB 가운데 터치 상·하단 바 숨김, 책갈피, 읽기 위치,
  글자 크기 및 배경 설정은 그대로 유지합니다.
- 정상 페이지 넘김 중 "본문을 표시하는 중" 문구는 나타나지 않습니다.

## 효과 방식과 제한

- 실제 물리 기반 3D 종이 메시가 아니라 Canvas 클립 곡선,
  종이 뒷면 반사와 동적 음영을 합성한 2.5D Page Curl입니다.
- 손가락으로 모서리를 붙잡고 멈추거나 원하는 각도로 직접 접는
  인터랙티브 3D 변형은 이 버전에 포함되지 않았습니다.
  터치 또는 스와이프로 넘기면 부드러운 자동 애니메이션을 실행합니다.
- 갤럭시 폴드 접힌/펼친 화면 비율에 맞춰 매번 실제 WebView
  가시 영역을 캡처하고 화면 크기에 맞춰 변형합니다.
- 실제 폴드에서의 애니메이션 FPS 및 확대/축소/회전 대응은
  직접 실기기로 검증해야 합니다.
