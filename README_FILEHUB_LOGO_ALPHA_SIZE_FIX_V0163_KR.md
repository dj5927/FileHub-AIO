# FileHub AIO v0.1.63 — O 글자 잘림·투명 배경·로고 절반 크기 수정

## 문제 및 원인

사용자가 갤럭시 폴드에서 FileHub AIO 홈 화면과 펼침 메뉴
스크린샷을 올림.

- 로고의 마지막 O 오른쪽 부분이 잘림.
- 펼침 메뉴 이미지 아이콘 배경이 투명하지 않고 어두운
  화면에서 흰색/회색 직사각형처럼 보임.
- FileHub AIO 글자 로고가 너무 큼; 절반 크기 요청.

직전 v0.1.62 PNG 파일을 실제 검사한 결과:

- 워드마크 원본 320x46 PNG의 알파 픽셀이 x=319 끝까지
  존재하여 O의 오른쪽 곡선 일부가 파일 경계에서 잘림.
- 아이콘 원본 128x122 PNG는 네 모서리 모두 RGBA
  (251, 248, 252, 24) 상태. 따라서 이미지 전체에
  반투명 흰색 바탕이 깔려 어두운 배경에서 사각형이 표시됨.

## 실제 변경

1. 워드마크에서 둥근 O의 왼쪽 반원 픽셀을 기준으로
   오른쪽 곡선을 정확하게 복원해 328px 너비를 만들고,
   PNG 양옆 20px, 위아래 10px의 완전 투명 여백을 더함.
   최종 워드마크는 368x66 RGBA PNG, 실제 표시 영역
   bbox=(20,10,348,56). 글자가 이미지 끝에 닿지 않음.
2. 이미지 아이콘은 기존 배경 알파 24/255를 제거하고
   전경의 실제 알파를 보정해 배경을 완전 투명하게 함.
   원래 파스텔 폴더/문서/사진/영상 디자인은 유지.
   최종 아이콘은 148x148 RGBA PNG로 여백을 추가함.
   네 모서리 알파가 모두 0임을 자동 검증.
3. 홈 상단 글자 워드마크를 기존 최대 180dp에서
   90dp로 **50% 축소**.
4. 왼쪽 펼침 메뉴 글자 워드마크를 기존 최대 174dp에서
   87dp로 **50% 축소**. 높이도 28dp에서 22dp로 조정.
5. 펼침 메뉴 파스텔 폴더 아이콘 크기도 40x43dp에서
   30x33dp로 줄여 글자 로고와 균형을 맞춤.
6. 기존 홈·펼침 메뉴 65dp 헤더 높이, 상태바 정렬,
   메뉴 기능, 스크롤, 즐겨찾기, 네트워크 접근 기능은 유지.
7. 앱 내부 표시 버전 0.1.63, versionCode64,
   versionName0.1.63. 패키지명 com.nasmount.mobile 및
   서명 인증서, 책갈피·NAS 연결·영상 시청 기록 유지.

## 검증

- Windows 호스트 Python PIL로 구 버전 이미지의 알파 및
  오른쪽 O 잘림을 분석.
- 이미지 보정 스크립트는 branding/fix_assets.py에 보관.
  신규 이미지 파일 크기, 콘텐츠 경계, 네 모서리 투명도 확인.
- FileHubBrandLayoutTest: 홈 90dp, 펼침 87dp 및
  폴드 화면 너비와 상태바 위치 테스트.
- Gradle testDebugUnitTest, lintDebug, lintVitalRelease,
  assembleRelease로 APK 빌드.
- v0.1.62 소스·APK는 덮어쓰지 않고 보존.

### 남은 확인

실제 갤럭시 폴드 기기가 ADB에 연결되지 않아 물리 기기에서
상단 로고 크기·기기의 아이콘 캐시·파일 앱의 표시 상태는
이번 APK 설치 후 사용자가 최종 확인해야 함.
