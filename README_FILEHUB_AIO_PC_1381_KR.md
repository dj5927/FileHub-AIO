# FileHub AIO PC v1.3.81

## 변경 사항
- 프로그램 표시 이름을 NAS Mount에서 **FileHub AIO**로 변경했습니다.
- 창 제목, 트레이 메뉴, Windows 프로그램 파일 이름을 변경했습니다.
- 설정 화면에 **설정 내보내기 / 설정 가져오기**를 추가했습니다.
- 기존 v1.3.80의 WebDAV/Excel 파일 잠금·저장 로직은 변경하지 않았습니다.

## 기존 설정 호환
- 기존 연결 목록과 비밀번호는 새 버전에서 그대로 읽습니다.
- 내부 설정 저장 경로 %APPDATA%\NASMount 및 Windows 자격 증명 대상 NASMount:{GUID}는 이전 버전과 호환성을 위해 유지합니다.
- Windows 자동 실행이 기존 버전으로 설정되어 있으면 새 FileHubAIO.exe를 실행할 때 등록 경로를 변경합니다.
- 업그레이드 전 실행 중인 NAS Mount를 **모든 업로드가 끝난 뒤 안전하게 종료**하고 새 파일을 실행하세요.

## 설정 내보내기
1. 메인 창의 톱니바퀴 **환경 설정**을 엽니다.
2. **설정 내보내기**를 눌러 .fhbackup 파일 위치를 선택합니다.
3. 10글자 이상 백업 암호를 두 번 입력합니다.
4. 연결 정보와 저장된 자격 증명, Google Drive·OneDrive 인증이 **AES-256-GCM**으로 암호화되어 저장됩니다.
5. 일부 연결의 저장된 인증을 찾지 못했으면 내보내기 완료창에 해당 연결이 표시됩니다.

## 설정 가져오기
1. Excel 등 열려 있는 파일을 저장하고 모든 연결을 **안전하게 해제**하세요.
2. **설정 가져오기**에서 .fhbackup 파일을 선택하고 암호를 입력합니다.
3. 기존 연결 목록을 새 목록으로 교체할지 확인합니다.
4. 기존 config.json은 같은 폴더에 .before-import-날짜.json 이름으로 별도 백업됩니다.
5. 프로그램을 종료하고 다시 실행합니다.

### 보안 및 주의 사항
- 백업 암호를 분실하면 백업 복구가 불가능합니다.
- PC용 .fhbackup은 Android 앱의 설정 전송 형식과 다릅니다. PC↔PC 복원에 사용하세요.
- Windows 시작 프로그램 설정은 대상 PC의 현재 상태를 유지합니다.
- 네트워크 드라이브 문자 중복이 발생하면 대상 PC에서 연결 문자를 조정하세요.
- OAuth 인증이 만료되거나 백업에 누락되었을 경우 해당 계정에 다시 로그인해야 합니다.
- 로그, 파일 캐시, NAS 문서 파일은 **내보내지 않습니다**.
- 실시간 NAS/Excel 멀티 PC 잠금 호환성은 연결된 실제 NAS에서 최종 확인해야 합니다.

## 실행
- 압축을 풀고 FileHubAIO.exe 실행
- tools 폴더와 내부 rclone, WinFsp 설치 파일, NASMountLockBridge.exe는 그대로 두세요.
