# NAS Mount Android v0.1.52 — 손가락 따라오는 실시간 책 넘김

## 지적된 문제와 원인

1. 만화책 속 이미지가 화면 중앙에 작게 보이는데도 종이 넘김
   애니메이션이 책 크기와 무관하게 검은 여백을 포함해 화면
   전체에서 동작했습니다.
   - 원인: v0.1.51 ReaderPageTransitions가 PageImage 전체의
     View 영역을 캡처하고 전체 View 크기만큼 Overlay를 그렸음.
2. 종이 넘김이 스와이프가 끝난 후 자동 재생될 뿐 손가락을
   따라 움직이지 않았고, 끌었다가 되돌리면 종이가 다시
   펼쳐지는 동작도 없었습니다.
   - 원인: 기존 ValueAnimator가 0→1로 자동 재생할 뿐
     MotionEvent.ACTION_MOVE 좌표와 연결되지 않았음.

## v0.1.52 구현

### 만화책
- PageImage의 표시 Matrix를 이용해 실제 이미지 경계를 계산.
  보이는 이미지와 현재 뷰포트의 교집합을 PixelCopy로 캡처하고
  오버레이 또한 그 경계에 딱 맞게 배치합니다.
- 이미지가 중앙에 작은 상태에서는 이미지 위에서만 손가락으로
  책장을 잡아 움직일 수 있으며, 검은 여백은 종이로 취급하지 않음.
- 만화의 한국식(왼쪽에서 오른쪽)·일본식(오른쪽에서 왼쪽)
  넘김 방향을 그대로 반영합니다.
- 손가락을 움직이는 동안 종이 말림/비스듬한 접힘이 따라오고,
  원래 위치로 돌아온 상태에서 손을 떼면 원래 페이지로 복귀.
- 충분히 넘겼다면 다음 페이지로 확정. 너무 짧게 끌면 취소,
  빠른 플릭은 기존 스와이프 방식대로 넘길 수 있습니다.
- 새로운 ZIP/RAR/7Z 이미지의 압축 해제는 백그라운드 작업으로
  선행하고, 새 페이지가 준비되면 종이 뒤쪽에 보여줍니다.
- 드래그 중 취소하면 미리 표시하던 새 이미지 대신 기존
  원본 페이지를 복원하고, 페이지 번호/진행률은 변경하지 않음.
- 두 손가락 확대 시 실시간 넘김을 취소하여 줌 동작 보호.
- 폴드 두 페이지, 합본 자동 분할, 밝기/명암, 다음 권 이동
  및 책갈피 등 기존 기능 유지.

### TXT
- 책 페이지형에서 이전/다음 텍스트를 미리 준비하고,
  손가락 좌표로 종이 접힘 정도/각도를 직접 갱신합니다.
- 아직 충분히 넘기지 않았거나 되돌려 놓으면 이전 페이지 복원.
- 폴드 펼친 상태에서도 페이지 좌표를 전체 펼침 화면 기준으로
  계산합니다.
- 12MB 초과 대용량 TXT의 48K자 구간 경계에선 다음 구간을
  백그라운드 계산 후 표시. 취소 시 이전 페이지 구간 복원.
- 세로 연속 스크롤 모드에서는 이전과 동일하게 스크롤.

### EPUB
- 같은 XHTML 장 안에서는 손가락 움직임에 따라 현재 장의
  다음 페이지를 종이 아래에 미리 준비하고, 원래 위치로
  돌아온 채 손을 떼면 스크롤 원위치 복원.
- 다른 XHTML 장의 경계에서는 다음 장을 비동기적으로 불러와
  표시하며, 드래그 취소 시 이전 장과 읽던 위치 복원.
- 기존 터치 책 넘김, 가운데 UI 숨기기, 책갈피/폰트/배경 유지.
- 일반적인 책 넘김 중 "본문을 표시하는 중" 문구는 표시 안 함.

## 종이 접힘 처리

- 손가락 가로 이동 거리로 접힘 진행도를 계산하고,
  위아래 대각선 이동으로 위·아래 접힘 모서리 위치를 달리하여
  종이가 비스듬하게 올라가는 모습을 표현합니다.
- 종이를 놓을 때 43% 이상 진행했다면 넘김을 완성하고,
  그 이하는 접힌 종이를 다시 원래대로 부드럽게 펴 줍니다.
- 짧고 빠른 플릭에는 완성 조건을 약간 완화합니다.
- 효과 선택 메뉴: 종이책 모서리 말림(실시간 드래그),
  슬라이드, 페이드, 효과 없음. 속도 설정은 기존대로 유지.
- 스와이프 중 손가락을 2개 사용하거나 화면 전환/설정 진입 시
  이전 페이지로 복구하고 진행 중인 캡처/애니메이션을 취소.
- Page Curl의 실제 화면 표현은 기존 Canvas 기반의 2.5D
  곡선, 종이 뒷면, 그림자 기법을 확장한 것입니다. 정교한
  3D 종이 메시는 아니므로 실제 종이의 완벽한 변형과는 다름.
