# FileHub AIO v0.1.93

## 수정 사항
- PDF 확대 상태에서도 화면 좌우 끝 고정 영역으로 이전·다음 책 페이지 이동
- 확대된 PDF 중앙에서는 기존대로 스크롤
- EPUB 읽기 화면에서 상하단 바를 숨기거나 다시 보일 때 책 페이지 정렬 유지

## 추가된 기능
- 폴더 보기·정렬에 '이 폴더에만 적용' 체크박스 추가
- 로컬·SD/USB·NAS/클라우드 폴더별 이름순·최신순 등 별도 정렬 저장
- 하위 폴더로 자동 상속하지 않으며, 체크 해제 시 기본 정렬로 복귀

## 기타 사항
- 기존 전체 기본 정렬과 책 진행도·북마크 유지
- 실제 휴대폰·TV에서 PDF 확대 넘김, EPUB 바 숨김, 폴더별 정렬 실기기 확인 필요
