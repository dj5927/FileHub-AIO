# FileHub AIO PC v1.3.146 — 로컬 캐시 및 OTA 정리

- 환경 설정 → 캐시 관리: 보존 시간 기본 30분, 연결별 최대 캐시 기본 5 GiB (조정 가능), 로컬 디스크 경로 변경, 완료 캐시 삭제, 파일 크기 확인.
- 읽기 및 전송 완료 캐시만 정리합니다. 열린 파일, 진행 중인 전송, 미전송·복구 데이터는 크기/시간 한도를 초과해도 보존합니다.
- rclone은 연결 중 자동 정리합니다. 직접 WebDAV의 실행 파일/이미지 읽기 캐시도 30초마다 보존 시간과 최대 크기를 확인합니다.
- 연결되지 않은 캐시는 모든 백엔드가 안전하게 종료된 상태에서 시작 시 및 주기적으로 정리합니다. 확인되지 않은 캐시는 보호합니다.
- 캐시 경로 변경은 모든 연결이 해제되고 기존 미전송/불명확 데이터가 남지 않은 경우에만 적용합니다. 경로와 보존 설정은 다음 연결부터 적용됩니다.
- 기존 날짜별 누적 로그를 정리하고 최근 30분의 분 단위 로그만 유지합니다.
- OTA 설치 완료 후 새 버전의 정상 시작을 확인하여 해당 버전과 이전 버전의 업데이트 ZIP, 압축 해제본, 설치 백업을 자동 삭제합니다. 설치 중인/더 새 버전의 자료는 보존합니다.
- 프로그램 설정, 계정 인증, NAS 원본 및 업로드 복구 저널은 정리 대상이 아닙니다.
- Android 배포와 Google OAuth 심사 설정은 변경하지 않습니다.
