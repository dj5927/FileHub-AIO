# FileHub AIO v0.1.89

## 수정 사항
- TXT 독서 설정에서 글씨 크기(pt), 줄간격(배), 좌우 여백(dp) 현재 수치 표시
- EPUB 독서 설정에서 글자 크기(pt), 줄간격(배), 좌우 여백(dp) 현재 수치 표시
- 만화책 설정에서 명암 대비(%), 밝기(-100~+100) 현재 수치 표시
- 모든 수치는 슬라이더를 움직이는 동안 즉시 갱신

## 기타 사항
- 기존 적용 버튼·폴더별 설정·슬라이더 범위 및 저장 값 유지
- 전체 설정 화면은 변경하지 않음
- Android 8 이상에서 사용 가능하도록 접근성 수치 안내 호환 처리
