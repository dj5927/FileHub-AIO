# NAS Mount Android v0.1.55 — TXT 연속성 및 추가기능 폴더 탐색

## TXT 누락 수정

v0.1.54에서는 페이지 하단에 여유만 늘렸으나 실제로는 다음 장과
내용이 이어지지 않는 현상이 확인됐습니다. 기존 BookPaginator는
12,000자 조각의 전체 문단을 미리 줄바꿈한 뒤 그 줄 높이를 누적했습니다.
하지만 개별 페이지 TextView에 넣는 순간 문단 줄바꿈을 다시 수행하며
보이지 않는 마지막 1~2줄이 페이지 경계 밖으로 밀려날 수 있습니다.

- 페이지를 잘라낼 때 페이지 시작 문자 위치에서 다시 StaticLayout을
  구성하고 실제 높이에 들어가는 마지막 줄까지를 해당 페이지로 지정.
- 페이지 계산기와 TextView의 줄바꿈을 SIMPLE 방식으로 통일해
  문단 전체 최적화로 줄바꿈 위치가 달라지지 않도록 함.
- 글꼴 크기, 줄간격, 좌우 여백 및 실제 폴드 화면 너비/높이 재계산.
- 상단/하단바 표시·숨김 시 구형 화면 크기로 계산한 비동기 결과는 폐기.
- 실제 TextView가 계산한 마지막 글자 높이도 검사하여 부족하면
  같은 읽기 위치에서 안전 높이를 더 확보한 뒤 다시 페이지 분할.
- 단일 페이지, 폴드 두 페이지 및 대용량 TXT 부분 페이지형 적용.
- 원본 TXT 내용을 삭제하거나 수정하지 않고 저장된 문자 위치 유지.

## 추가기능 — 하위폴더 바로보기

- 동영상·만화책·소설책을 클릭하면 해당 용도로 지정된 상위폴더의
  바로 아래 하위폴더를 통합 목록으로 보여줌.
- 지정 폴더에 하위폴더가 없으면 지정 폴더 자체를 대신 표시.
- 로컬, SD/USB SAF, 저장된 NAS 및 클라우드 연결 경로를 지원.
- 네트워크 목록은 백그라운드로 읽고, 연결 실패 시 설정을 지우지 않음.
- 원하는 하위폴더를 클릭하면 원래 파일관리자 위치에서 탐색.

## 오른쪽 상단 + 버튼 — 폴더 탐색기

- 지정 폴더가 없어도 + 버튼 상시 표시.
- 메인 저장소, 다운로드, 연결된 SD/USB, 이미 권한을 받은
  SAF 문서 폴더 및 연결된 네트워크 저장소를 단계별로 탐색.
- 현재 폴더 지정 버튼을 누르면 기존 폴더 용도 설정에 등록.
- 만화책은 comic, 소설책은 text(TXT/EPUB), 동영상은 기존
  동영상 폴더 설정에 추가하며 별도 임시 즐겨찾기를 만들지 않음.

## 길게 누름 → 제외하기: 실제 폴더 용도 지정 해제

- 추가기능 목록에서 해당 폴더를 길게 누르면 제외하기 가능.
- **목록에서만 숨기는 것이 아니라 폴더의 실제 해당 용도를 해제.**
- 직접 지정된 폴더는 해당 지정 항목을 삭제함.
- 상위 폴더의 설정을 물려받던 하위 폴더는 제외 규칙으로
  해당 폴더와 그 아래에만 용도가 적용되지 않도록 처리함.
- 형제 폴더의 용도, 다른 책/영상 카테고리는 변경되지 않음.
- 실제 TXT/EPUB/만화책 독서 뷰어 적용 및 동영상 자막 숨김 판단에도
  예외 규칙이 반영되며 +로 재지정하면 다시 활성화됨.
- 파일, 원본 폴더, 책갈피, NAS 연결 및 즐겨찾기는 보존함.

## 검증 및 제한

- v0.1.54를 원본 그대로 보존하고 독립된 v0.1.55 작업 폴더 생성.
- 컴파일, 단위 테스트, Android Lint, 서명, SHA256은 작업일지 참조.
- 경로 격리, 실제 용도 해제의 상속 규칙, 문자 오프셋의 연속성을
  자동 테스트로 검증함.
- 갤럭시 폴드 실기기는 ADB에 연결되지 않아 화면의 글자 렌더링,
  원격 NAS 목록 응답 및 SD/USB 폴더 선택은 직접 시험하지 못함.
