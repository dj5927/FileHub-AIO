# FileHub AIO Android v0.1.77 - 콘텐츠 뒤로가기 및 상단 경로 수정

## 수정한 원인

- 추가 기능의 동영상·만화책·소설책 목록은 사용자가 지정한 폴더의 **직계 하위 폴더**를 보여주는데, v0.1.75/76은 그 하위 폴더를 뒤로가기 최상위 기준으로 오인했습니다.
- v0.1.76에서 상단 경로를 클릭할 때 지정한 기준보다 위로 이동하지 못하도록 차단해, 예를 들어 `2.영화` 항목이 눌리지 않는 문제가 있었습니다.

## v0.1.77 동작

- 콘텐츠 목록의 각 진입 항목이 어떤 **사용자 지정 원본 폴더**에서 나온 것인지 계산해서, 폴더의 실제 저장소 경로/소유자와 함께 뒤로가기 경계를 저장합니다.
- `2.영화/4_드라마`를 지정해 목록에 표시된 `가족계획 6부작 완결`에 들어갔다면 뒤로가기는 `4_드라마`로 이동하고, 이 지정 폴더에서 한 번 더 뒤로가면 홈으로 이동합니다.
- 상단의 `2.영화` 같은 더 상위 경로도 누를 수 있습니다. 상위 경로를 터치해 이동하면 해당 경로를 새로운 경계로 업데이트해, 거기서 뒤로가면 홈으로 돌아옵니다.
- 일반 파일 탐색 경로 및 동영상 실제 장면 썸네일은 기존 기능을 유지합니다.
- 다중 등록 폴더가 중첩된 경우 현재 열려 있는 항목을 포함하는 **가장 구체적인 등록 경로**를 경계로 사용합니다.
- NAS 계정 ID가 다르면 등록 경계가 섞이지 않도록 구분하고, 로컬/SAF/레거시 SD/USB 저장소 경계도 유지합니다.

## 검증 한계

- Gradle `testDebugUnitTest`, `lintDebug`, `lintVitalRelease`, `assembleRelease` 빌드와 경계 결정 테스트를 통과했습니다.
- 실제 기기의 뒤로가기 제스처 및 특정 NAS 경로 동작은 아직 직접 테스트하지 못해 설치 후 확인이 필요합니다.
- 기존 v0.1.76 APK/설정·썸네일 캐시·기존 소스 백업은 보존합니다.
