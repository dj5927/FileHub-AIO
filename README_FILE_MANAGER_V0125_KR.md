# NAS Mount Android v0.1.25 — 다중 선택 파일관리자

기준 소스: v0.1.24. 플레이어·SMI/SRT·NextLib FFmpeg·Fold7 레이아웃 및 기존 원격 연결 코드를 그대로 유지한 채 파일관리자 작업 기능을 추가했습니다.

## 변경된 사용 방법

1. **파일 또는 폴더를 길게 누르면 다중 선택 모드로 전환**합니다. 기존의 `폴더 열기`를 포함한 팝업이 뜨지 않습니다. 다른 항목을 가볍게 탭하면 하나씩 추가 선택하거나 선택 해제합니다. 선택한 행은 청록색으로 표시됩니다.
2. **상단 선택 바**: 닫기(X), 선택 개수 / 현재 목록 개수, 오른쪽 `▢/▣` 전체 선택 및 해제 버튼을 표시합니다. 안드로이드 뒤로 가기는 선택 모드만 종료합니다.
3. **하단 작업 바**: `복사`, `이동`, `이름 변경`, `삭제`, `더 보기`. 이름 변경은 단일 선택에서만 지원합니다. 삭제는 선택 항목과 하위 폴더까지 영향을 줄 수 있음을 확인받습니다.
4. **복사/이동**: 하단 바가 `취소 / N개 복사·이동 대기 / 붙여넣기`로 바뀝니다. 홈과 원격 연결 화면을 거쳐 **내장 저장소, SD카드(SAF), SMB, FTP, SFTP, WebDAV**의 다른 폴더로 이동한 후 붙여넣을 수 있습니다.
5. **더 보기**: 폴더 즐겨찾기 추가/해제, 동영상 폴더 설정/해제, 열기, 네트워크 단일 파일 다운로드, 선택 해제.
6. **즐겨찾기 별 표시**: 현재 폴더를 등록한 상태는 **★ 금색**, 미등록 상태는 **☆ 흰색**으로 표시합니다. WebDAV 등 원격 폴더 상단의 별·즐겨찾기 버튼도 동일한 저장 상태를 즉시 반영합니다.

## 저장소 동작과 안전 조치

- 네트워크 간 복사: 기존 RemoteProvider의 스트림 읽기/임시 업로드 후 MOVE를 사용하며 **전체 파일을 RAM에 올리지 않습니다**. 다운로드 뒤 재업로드하는 대신 스트림을 연결합니다.
- 같은 NAS 연결 내부의 이동은 서버 측 이름 변경을 사용합니다. 로컬 같은 볼륨의 이동은 덮어쓰지 않는 NIO move를 우선합니다.
- 복사는 대상에 같은 이름이 있을 때 중단합니다. 로컬 파일 생성은 CREATE_NEW로 원자적으로 열어 기존 파일을 덮어쓰지 않습니다.
- 원본은 대상 복사가 성공적으로 닫힌 후에만 삭제합니다. 다른 저장소로의 이동은 여러 파일을 한꺼번에 처리하는 원자적 트랜잭션이 아니므로 **오류 발생 시 이미 복사/이동한 일부 항목이 남을 수 있습니다**. 완료 개수 안내를 통해 수동 확인이 가능하도록 했습니다.
- 폴더 복사는 하위 파일까지 처리합니다. 동일 저장소에서 자기 폴더 내부로의 복사와 심볼릭 링크는 차단합니다. 최대 깊이/항목 수 제한으로 비정상 재귀 동작을 막습니다.
- TeraBox 및 MYBOX는 현재 Android 원격 제공자의 쓰기 기능이 없으므로 **복사 원본으로만 이용**할 수 있고, 붙여넣기·이동·이름 변경·삭제 대상은 아닙니다. Android의 미디어 분류 화면은 복사 원본으로 사용할 수 있으나 삭제·이름 변경은 일반 저장소 탐색 화면에서 진행해야 합니다.
- 모든 원격 폴더 목록 캐시는 작업 성공 또는 일부 실패 이후 무효화합니다.
