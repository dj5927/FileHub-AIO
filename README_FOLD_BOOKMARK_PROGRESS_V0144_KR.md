# NAS Mount Android v0.1.44 — 폴드 대응 / 책 넘김 / 책갈피 / 독서 진행도

## 1. 폴드 펼침과 접힘

- ComicBookActivity는 폴드·회전 시 이미 내려받은 압축 원본을
  유지하면서 화면 폭에 맞춰 페이지 이미지만 다시 구성합니다.
- BookTextActivity는 화면 변경 시 페이지 레이아웃을 다시 만들고
  저장된 읽기 위치로 복원합니다.
- 읽던 위치는 로컬 앱 설정에 즉시 보존하며, 새 화면에서 다시 복원합니다.
- 화면 폭이 600dp 이상이면 만화책은 2장 펼침, 텍스트책은 2쪽
  양쪽 열을 지원합니다. 설정에서 각각 끌 수 있습니다.
- 폰을 접어 화면이 좁아지면 한 장/한 쪽 보기로 자동 돌아갑니다.
- 2쪽 보기는 양쪽 페이지를 한 번에 넘기며, 일본식은 화면 배치를
  우→좌 순서로 반전합니다. 마지막 페이지가 홀수면 1장만 표시합니다.
- 만화책의 가로 폭 맞춤 기능을 켜면 두 장 펼침은 비활성화됩니다.
- 텍스트책 세로 스크롤 모드에서는 두 열로 페이지를 쪼개지 않고
  중앙 폭 제한된 한 열을 계속 아래로 스크롤합니다.

## 2. 만화책

- 만화책 화면의 이미지 아무 곳이나 한 번 누르면 상단 제목/책갈피/
  설정과 하단 페이지/슬라이더 바가 동시에 숨겨지거나 다시 보입니다.
- 이미지를 좌/우로 스와이프하면 한국식/일본식 설정대로 페이지가 넘어갑니다.
- 책 넘김 효과: 없음 / 짧은 슬라이드 / 부드러운 페이드.
- 기존 두 손가락 확대 및 더블탭 확대·드래그는 유지합니다.
- 펼침 모드에서는 ZIP/7Z/RAR 안의 페이지만 개별 추출해
  최대 2048px 샘플 이미지 2개로 제한된 펼침 이미지를 만듭니다.
- 만화책 압축 원본은 변경하지 않습니다. 원격 파일은 기존처럼
  1.5GB 이하의 압축 원본을 임시 보관한 뒤 개별 페이지만 해제합니다.
- 진짜 3D 종이 모서리 컬/물리 시뮬레이션은 이번 버전에 포함하지 않습니다.

## 3. 텍스트책

- 상단 Aa → 읽기 방식에서 '책 넘김 · 좌우 페이지' 또는
  '세로 스크롤 · 연속 읽기'를 선택합니다.
- 페이지 모드에서는 슬라이드/페이드 효과 선택 가능.
- 스크롤 모드에서는 책 전체를 세로 스크롤하며, 현재 화면에
  보이는 첫 줄의 글자 위치를 책의 독서 위치로 기록합니다.
- 오른쪽/왼쪽 버튼으로 화면 한 페이지 정도 위아래 이동 가능.
- 기존 폰트·크기·줄간격·여백·종이색/야간 모드 설정은 유지합니다.
- 폴드를 펼친 텍스트책 페이지 모드에서는 두 쪽을 양쪽 열로 표시합니다.
- 설정 전환·접힘/펼침 후에도 읽던 글자 위치 기준으로 복원합니다.

## 4. 두 뷰어 공통 책갈피

- 상단 ☆ 버튼 → 책갈피 메뉴.
- 현재 페이지(만화책) 또는 본문의 위치(TXT)를 추가/해제.
- 책갈피 목록에서 항목으로 이동하거나 원하는 항목만 삭제할 수 있습니다.
- 책갈피는 파일별·계정별로 저장되며 앱을 닫아도 유지됩니다.
- 기존 v0.1.43의 마지막 읽던 페이지/문자 위치 기록이 있다면
  첫 실행 시 읽기 위치로 사용하고 이후 공통 기록 저장소로 갱신합니다.

## 5. 파일 목록 진행률 표시

- 기존 '폴더 용도 설정'에서 만화책 또는 TXT 독서용 폴더로
  설정한 폴더와 그 하위 폴더 내 해당 책 파일에만 표시합니다.
- 파일을 한 번 연 뒤부터 파일 용량 옆에 녹색 소형 라벨
  (예: 2.2GB · 77% 읽음)이 표시됩니다.
- 만화책은 현재 표시된 마지막 페이지/전체 페이지 비율,
  TXT는 현재 화면에 표시된 마지막 글자/전체 본문 비율입니다.
- 파일 목록으로 돌아오면 진행도가 갱신됩니다.
- 다른 일반 ZIP/7Z/RAR/TXT 파일은 독서 진행률을 표시하지 않고
  기존 압축 및 편집 동작을 그대로 유지합니다.
- NAS 계정/SAF 문서 URI/로컬 경로별로 서로 다른 책은 별도 기록합니다.

## 6. 검증 범위 및 제한

- Gradle JUnit + Android Lint + assembleRelease, 서명 및 해시 검증은
  프로젝트 작업일지의 v0.1.44 항목을 참고하세요.
- 실제 Galaxy Fold에서 펼침/접힘과 터치 조작을 완료한 상태는
  아닙니다. 개발 PC에 연결된 Fold 실기기가 없는 경우 별도 검증이 필요합니다.
- 진행률은 읽은 페이지/글자 위치 추정치이고 실시간 실제 읽은 시간은 아닙니다.
- 변경된 책 내용, 이름, 저장소 경로에 따라 기록이 별도로 남을 수 있습니다.
- 대용량 TXT 세로 스크롤 모드의 표시 지연 가능성과 RAR 변종 제한은
  기존 책 뷰어 베타의 제한 사항으로 유지됩니다.
