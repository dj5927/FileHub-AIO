# NAS Mount Android v0.1.49 — EPUB 본문 로딩 안내 완전 제거

## 수정 요청

사용자 Galaxy Fold에서 EPUB을 한 장씩 넘길 때 화면 가운데
"본문을 표시하는 중..."과 같은 문구가 계속 나타남.
v0.1.48에서 첫 장 로딩 후 표시를 억제했지만 재현되었다고 보고됨.

## 이번 버전의 처리

- EPUB 독서 화면의 중앙 상태 텍스트는 기본적으로 빈 문자열이며
  생성 직후 GONE 상태입니다.
- **최초 책 열기, 같은 장의 페이지 넘김, 다른 장으로의 이동 모두
  로딩 문구를 화면 중앙에 표시하지 않습니다.**
- EPUB 원본 읽기 실패, 파서 문제, 본문 로드 오류가 실제로
  발생했을 때만 중앙에 오류 원인을 표시하도록 분리했습니다.
- 기존 v0.1.48의 최초 EPUB 로딩 여부(initialChapterRendered)에
  의존하는 조건을 아예 제거했습니다. 이 조건이 업데이트되지 않아
  로딩 문구가 재등장할 수 있는 경로도 함께 사라졌습니다.
- EpubReaderStatus 정책과 테스트를 추가해
  처음 열기·장 로딩·일반 페이지 넘김 상태에서 문구가 나타나지
  않으며, 실제 오류에서만 문구가 표시되는 규칙을 검증합니다.
- WebView는 책 전체를 다시 다운로드하지 않고 기존처럼 각
  EPUB 장의 XHTML만 가져옵니다. 안내 문구는 없지만 장 이동
  시 단말기 처리 속도에 따른 짧은 렌더링 시간은 있을 수 있습니다.

## 사용자 확인

- NASMount_Android_v0.1.49_EPUB_NO_LOADING_MESSAGE_BETA.apk
  설치 후 안드로이드 앱 정보에서 NAS Mount 버전 0.1.49 확인.
- EPUB 페이지를 좌우 터치로 여러 번 넘기고, EPUB 장 경계도 넘어가
  중앙 안내 문구가 한 번도 나타나지 않는지 확인.
- 큰 TXT/EPUB, ZIP/RAR/7Z 만화책, NAS 연결, 책갈피, 폴더 용도
  설정은 기존 버전과 동일하게 유지됩니다.
