# FileHub AIO v0.1.100

## 수정 사항
- 폴드를 접으면 홈 버튼 팝업 확인창의 제목만 보이고 메시지·버튼이 잘리던 문제 수정
- 기존 동영상 Activity의 창 크기에 종속된 AlertDialog를 독립적인 Android 오버레이 카드로 교체
- 접은 화면과 펼친 화면에서 각각 실제 화면 너비 기준으로 확인창 크기를 계산
- 폴드 접기·펼치기 중 화면 크기 변경 이벤트가 발생하면 확인창 너비를 자동으로 다시 계산
- 확인창 높이를 내용에 맞춰 자동 조정해 버튼이 화면 밖으로 잘리지 않도록 처리

## 유지 사항
- 홈 버튼 시 팝업 재생 / 재생 정지 선택
- 팝업 X로 닫을 때 오디오 및 영상 플레이어 완전 정리
- PIP 뒤로 / 일시정지 / 앞으로 버튼, 전체화면 복귀 기능
- 기존 독서·원격 저장소·재생 기록 기능

## 기타 사항
- 홈 화면 위 확인창에는 기존과 같이 Android '다른 앱 위에 표시' 권한 필요
- 권한 미허용 시 PIP 자체의 계속 재생/종료 액션 사용
- 실제 삼성 폴드 기기 화면 전환·권한 관련 E2E 테스트는 별도 검증 필요
