# FileHub AIO v0.1.97

## 추가된 기능
- 파일 검색창의 **하위 폴더 포함 검색** 체크박스
- 내장 저장소·SD/USB·원격 NAS/클라우드 파일명 하위 폴더 검색
- PDF를 폴드 펼침 화면에서 **두 페이지 나란히 보기** (Aa 설정에서 전환)

## 수정 사항
- TXT·만화책 뒤로 넘김 중 이전 내용이 갑자기 교체되던 화면 처리 수정
- PDF 두 페이지 보기에서 좌우 넘김, 책갈피 및 읽던 위치 연결

## 기타 사항
- 하위 폴더 검색은 별도 작업으로 진행하며 사용자가 닫으면 취소
- 대량 NAS 파일 검색은 최대 300개 결과·30,000개 항목·4,000개 폴더·32단계로 제한
- 원본 파일과 이전 버전 유지
