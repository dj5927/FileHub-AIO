# FileHub AIO Android v0.1.76 - 동영상 실제 장면 썸네일 및 콘텐츠 뒤로가기 보정

## 동영상 미리보기
- 파일 목록과 격자 보기의 동영상 아이콘을 실제 영상 프레임 썸네일로 바꿉니다. 미리보기 위에는 작은 재생 표시를 겹칩니다.
- 로컬 파일, Android SAF/SD/USB 문서, MediaStore URI는 Android MediaMetadataRetriever를 사용합니다.
- NAS 및 연결된 원격 동영상은 RemoteProvider.openStream의 위치 지정 읽기를 활용하여 프레임을 추출합니다. 한 번 시도할 때 블록 192KiB, 최대 32개(약 6MiB)로 전송을 제한합니다.
- 각 동영상 썸네일은 앱 캐시 디렉터리에 JPEG로 저장하고 파일 크기·수정 시각·저장소 경로 변경 시 캐시를 새로 만듭니다. 캐시 파일은 최대 160개로 제한합니다.
- 보기 및 정렬에서 `동영상 실제 장면 미리보기 (기본 켜짐)` 설정을 별도로 끄거나 켤 수 있습니다. 기존 이미지 썸네일 옵션은 그대로 유지합니다.
- Android 8.0(API 26)에서는 getFrameAtTime, Android 8.1 이상에서는 getScaledFrameAtTime을 사용합니다.
- NAS 네트워크 오류, 코덱 미지원, 파일 크기 미확인, Range 지원 실패 시 목록은 계속 표시하고 기존 동영상 아이콘을 유지합니다. 모든 형식/모든 NAS에서 성공을 보장하지 않습니다.

## 콘텐츠 최상위 폴더 뒤로가기 수정
- `추가 기능 → 동영상/만화책/소설책`에서 NAS 폴더를 열 때 과거 화면의 경로가 아닌 실제 선택한 폴더 경로를 먼저 뒤로가기 기준점으로 등록합니다.
- 등록된 폴더 하위에서는 기기 뒤로가기로 부모 폴더까지 단계적으로 돌아갑니다. 지정 폴더에서는 뒤로가기로 홈에 이동합니다.
- 상단 경로 표시(breadcrumb)를 눌렀을 때 지정 폴더 위의 물리적 저장소 경로로 나가는 것을 막고 지정 폴더로 제한합니다. 일반 파일 탐색은 기존 방식입니다.
- NAS 연결 ID 및 로컬/SAF 저장소 구분을 유지합니다.

## 테스트 및 주의
- Gradle :app:testDebugUnitTest :app:lintDebug :app:lintVitalRelease :app:assembleRelease 통과. JVM 테스트에 영상 확장자·Range 경계·NAS 다운로드 제한 및 breadcrumb 경계 회귀 테스트 추가.
- 기기 ADB가 연결되지 않아 실제 휴대전화의 동영상 프레임 추출/제스처/원격 NAS 스트리밍 속도는 아직 실기기 검증되지 않았습니다.
- 기존 v0.1.75와 v0.1.74 소스 ZIP/배포 APK, NAS 연결 및 설정을 보존하며 v0.1.76은 별도 APK로 배포합니다.
