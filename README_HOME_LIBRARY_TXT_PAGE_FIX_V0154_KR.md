# NAS Mount Android v0.1.54 — TXT 마지막 줄 / 홈·지정 폴더 모아보기

## 1. TXT 페이지 마지막 줄 잘림 방지

- 증상: 갤럭시 폴드를 펼쳐 TXT 양쪽 페이지형으로 읽으면
  가끔 오른쪽 맨 아래에 다음 한 줄이 반쯤 잘려 나타남.
- 원인: StaticLayout으로 계산한 페이지 높이와 실제 Android
  TextView가 글리프와 줄간격을 배치하는 높이 사이에 미세한
  차이가 있음. 컨테이너의 남은 높이까지 정확히 채우면 일부
  기기/폰트 조합에서 맨 마지막 줄이 잘릴 수 있음.
- 변경: BookPageSafety.usableHeight()로 한 줄 이상의 여유를
  배치 높이에서 제외해 다음 페이지로 넘깁니다.
- 현재 글꼴 크기, 글꼴 자체의 실제 fontSpacing, 줄간격 배수를
  함께 반영하여 여유 높이를 다시 계산합니다.
- 페이지형의 단일/양쪽 두 페이지와 12MB 초과 대용량 TXT의
  부분 페이지 계산에도 동일하게 적용합니다.
- TextView 하단 내부 여백을 8dp에서 12dp로 증가시켰습니다.
- 글꼴/줄간격/여백 설정을 변경하면 새 크기로 다시 페이지를
  계산합니다. 내용은 삭제·수정하지 않고 페이지 경계만 바뀝니다.
- 연속 세로 스크롤 모드는 기존 스크롤 방식을 유지합니다.

## 2. 파일 선택 → 더 보기 메뉴 간소화

- 기존 메뉴의 열기와 다운로드 폴더에 저장 두 항목 제거.
- 남은 항목: 즐겨찾기 추가/해제, 폴더 용도 설정,
  선택 파일 압축하기, 선택 해제.
- 파일을 직접 터치해 여는 기능, 네트워크 파일 다운로드 기능의
  기타 경로와 기존 파일 복사·이동은 삭제하지 않았습니다.

## 3. 홈 화면 재구성

기존 저장소 바로가기를 보존하며 SD·USB 이동식 장치가 있을 때
기존 이동식 저장소 타일 동작도 변경하지 않았습니다.

홈 화면의 새 순서:

1. 저장소: 메인, 다운로드, 이미지, 오디오, 동영상,
   SD/이동식 저장소가 있는 경우 기존 타일 포함.
2. 얇은 구분선.
3. 추가기능: 동영상 / 만화책 / 소설책.
4. 원격 저장소: 기존 NAS·클라우드 연결 관리.

- 홈 하단 즐겨찾기 목록은 완전히 제거했습니다.
- 왼쪽 탐색 메뉴의 즐겨찾기는 그대로 유지하며 즐겨찾기
  등록·삭제 기능과 저장된 즐겨찾기도 보존합니다.

## 4. 동영상·만화책·소설책 지정 폴더 모아보기

- 새 별도 등록 정보가 아니라 기존 사용자 지정 폴더 설정을
  직접 불러옵니다.
- 동영상: nas_video_settings/subtitle_hide_folders 안에 저장된
  동영상용으로 직접 지정된 폴더.
- 만화책: nasmount_reader_folders/book_folder_scopes_v1 중
  comic으로 직접 지정된 폴더.
- 소설책: 같은 설정 중 text로 직접 지정된 TXT/EPUB 폴더.
- 각각 누르면 지정된 폴더들의 목록이 나오며 로컬 경로, SD/SAF
  폴더, NAS/원격 계정의 폴더를 구분해 보여줍니다.
- 선택 시 원래 저장소의 해당 폴더로 바로 이동합니다.
- 연결이 사라진 원격 계정이나 접근 권한이 없는 SAF 저장소는
  임의로 다른 폴더에 연결하지 않고 안내 메시지를 표시합니다.
- 오래된 Android SAF storage: 문서 ID와 saf: 형식,
  local: 및 remote: 동영상 지정 설정을 지원합니다.
- 지정 폴더명 정렬, 다른 원격 계정의 동일한 이름 구분,
  로컬/원격 루트 폴더 지정 처리 및 권한 범위 경계 검증을
  AssignedFolderCatalogTest에 추가했습니다.

## 5. 검증 범위

- 기존 패키지/앱 서명을 유지해 v0.1.53 위에 덮어 설치 가능.
- 이전 앱 설정, 연결 계정, 즐겨찾기, 독서 진행률/책갈피를
  초기화하거나 삭제하지 않았습니다.
- 코드 컴파일, 단위 테스트, Android Lint 및 릴리스 APK 서명
  검증은 작업일지.md의 v0.1.54 항목에 기록.
- 실제 갤럭시 폴드 실기기에서 글자 잘림 재현과 UI 터치,
  USB/SD 및 여러 NAS 서버의 폴더 이동은 직접 검증하지 못함.
  사용 중인 폰에서 확인이 필요한 베타 버전입니다.
- 전체 소스 ZIP과 APK는 기존 버전과 별도 파일로 보존했습니다.
