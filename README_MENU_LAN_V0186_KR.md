# FileHub AIO v0.1.86 — 메뉴 간소화 / LAN 설정 전송

## 이번 수정

- 상단 오른쪽 ⋮ 메뉴는 **즐겨찾기 보기 / 원격 저장소 보기 / 저장소 접근 권한 / 업데이트 확인** 네 항목만 표시합니다.
- ⋮ 메뉴의 중복 앱 정보 팝업(잘못 표시되던 v0.1.83)과 휴대폰→TV 계정 전송 항목을 제거했습니다. 앱 버전은 설정 > 일반 > 현재 앱에만 표시합니다.
- 원격 저장소의 설정 파일 내보내기 · 가져오기에서 기기 간 이동 메뉴의 QR로 연결하기 링크를 제거했습니다.
- Android TV 홈 화면의 별도 QR 연결 행도 제거했습니다.
- 기존 동일 네트워크 자동 설정 전송, 파일 백업/복원, 연결 목록, 계정 암호화, TV 최종 승인, 시청·독서 진행률의 기기별 저장 정책은 유지했습니다.

## 동일 네트워크 설정 전송

1. TV FileHub에서 원격 저장소 > 설정 파일 내보내기 · 가져오기 > 기기 간 설정 이동 > 가져오기를 누릅니다.
2. 휴대폰 FileHub에서 같은 메뉴의 내보내기를 누릅니다.
3. 수신 대기 중인 TV가 한 대면 자동 선택되고, 여러 대면 기기 목록에서 선택합니다.
4. 휴대폰에서 전송 대상 기기 이름과 IP를 확인한 후 암호화 전송을 승인합니다.
5. TV에서 설정 내용을 확인해 **병합** 또는 **전체 교체**를 승인해야 실제 저장됩니다.

전화기와 TV는 같은 LAN에 있어야 하고 공유기 클라이언트 격리가 켜져 있으면 서로 발견하지 못할 수 있습니다. QR 주소 없이 진행합니다. 과거 QR 전송용 내부 처리 코드는 구형 딥링크 호환성 목적으로 남겨두었지만, 새 UI에서 노출하지 않습니다.
