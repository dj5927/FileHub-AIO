# FileHub AIO Android v0.1.104 — 일반 사진첩처럼 이어지는 스와이프

기존 v0.1.103에서는 손가락을 놓으면 현재 사진을 먼저 지우고
새 사진을 다운로드·디코딩했습니다. 그 결과 검은 화면 뒤에
다음 사진이 나타나는 부자연스러운 전환이 발생했습니다.

이번 버전은 화면을 완전히 교체하는 대신 같은 너비의 사진
3장을 나란히 배치하고, 손가락을 좌우로 움직이는 동안
세 장의 위치를 함께 이동시킵니다.

- 왼쪽으로 밀기: 현재 사진이 왼쪽으로 나가며 오른쪽의 다음 사진이 이어서 들어옵니다.
- 오른쪽으로 밀기: 현재 사진이 오른쪽으로 나가며 왼쪽의 이전 사진이 이어서 들어옵니다.
- 손가락을 놓으면 이동 거리와 속도를 판단하여 130~280ms 감속 애니메이션으로 다음 사진에 정착하거나 취소된 스와이프를 제자리로 되돌립니다.
- 다음/이전 사진을 미리 불러옵니다. 느린 NAS 또는 클라우드 사진은 로딩 완료 전까지 기존 사진을 유지하며, 다운로드 후 정상 전환합니다.
- 실제로 다음 사진이 없는 경우 검은 화면을 드러내는 빈 페이지 이동을 하지 않습니다.
- 확대 상태에서 사진을 이동하거나 두 손가락으로 확대하는 동작은 사진 넘김으로 처리하지 않습니다. 기존 두 번 탭 확대·축소 및 GIF 지원을 유지합니다.
- 로컬 파일, SAF 방식 SD/USB, 원격 프로필 폴더에서 같은 사진 넘김 정책을 사용합니다.
- 화면에 움직이는 ImageView의 상대 좌표 대신 손가락의 고정된 실제 화면 좌표를 추적하여 이동 중 좌표가 반동하는 문제를 방지합니다.
- 화면에 필요한 현재·양옆 사진만 우선 보관해 메모리 사용을 제한하며, 임시 이미지 파일은 뷰어 종료 시 정리합니다.

검증: ImagePagerMotionPolicyTest와 기존 ImageSwipePolicyTest 등
Android 전체 단위 테스트, Lint 및 릴리즈 APK 빌드.

주의: 터치 추적·애니메이션을 실제 Galaxy Fold 화면에서 조작하는
실기기 테스트는 연결된 ADB 기기가 있어야 추가 확인할 수 있습니다.
사용자 기기에서는 빠른 연속 스와이프, 느린 WebDAV 사진,
GIF, 확대 후 이동, 폴드 접힘·펼침을 확인해 주세요.
