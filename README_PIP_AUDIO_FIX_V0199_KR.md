# FileHub AIO v0.1.99

## 수정 사항
- 팝업 닫기(X) 시 오디오와 영상을 중단하고 플레이어 완전히 해제
- 새 영상 재생 시 기존에 남은 팝업 플레이어를 먼저 종료
- 동영상 상단의 사전 팝업 선택 버튼 제거: 재생 중 홈으로 이동 시 PIP 전환

## 추가된 기능
- 팝업 터치 시 '10초 뒤로 / 재생·일시정지 / 10초 앞으로'
- 홈 이동마다 '팝업 계속 재생 / 재생 종료' 선택
  - 최초 한 번 Android '다른 앱 위에 표시' 권한을 허용하면 홈 화면 확인창 표시
  - 권한 미허용 시 팝업 터치 후 시스템 컨트롤의 계속 재생/종료 버튼 선택
- 동영상 추가 설정에서 홈 확인창 권한을 다시 설정 가능

## 기타 사항
- Android PIP의 기본 창 크기 및 닫기/전체화면 아이콘은 시스템에서 관리
- 시스템 PIP에는 별도 타임라인 SeekBar를 배치할 수 없어 10초 이동 버튼 사용
- 기존 재생 위치·자막·NAS 스트리밍 기능 유지
