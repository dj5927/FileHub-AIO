# FileHub AIO PC v1.3.145 — Google Drive 선택적 동의 및 인증 완료 화면

- 기존 FileHub Desktop Client ID 및 PKCE/로컬 루프백 방식 유지.
- Drive 전체 접근과 계정 이메일 확인을 요청하고 사용자의 선택 결과를 Google 토큰 응답에서 확인.
- 이메일은 Google 계정 확인과 브라우저 완료 화면에만 표시. 별도의 이메일 수집/로그 저장 없음.
- Drive 전체 접근 권한이 승인되지 않으면 새 Drive 연결과 인증 정보 저장을 중단.
- 인증 완료 시 전체 HTTP 요청 헤더를 처리하고 브라우저에 정상 결과 페이지 제공.
- 최대 2분간 안전한 로컬 완료 URL을 유지하며 재요청해도 OAuth 코드를 다시 교환하지 않음.
- 기존 저장된 인증은 강제 폐기하지 않으며 타 저장소 및 WinFsp 구성 변경 없음.
- v1.3.144의 검증된 LockBridge 및 엔진 패키지는 동일하게 유지.
- Google Cloud 심사 진행 상태는 배포와 별개. Google이 허용한 계정만 연결할 수 있으며 승인 완료를 표시하지 않음.

2026-11-24: 사용자 확인을 받은 선택적 동의/완료 화면 테스트판을 정식 PC 배포 기준으로 승격.
