# FileHub AIO v0.1.87 — LAN 전송과 외부 네트워크 QR 전송 분리

## 앱 메뉴

원격 저장소 → 설정 파일 내보내기 · 가져오기 → 설정 이동 및 백업

1. **LAN 자동 전송:** 같은 Wi-Fi에서 가져오기 대기/자동 검색/내보내기
2. **인터넷 QR 전송:** TV QR 표시·받기 / 휴대폰 QR 스캔·보내기 /
   받는 기기의 공개 HTTPS 중계 서버 주소 설정
3. **파일 백업·복원:** 기존 비밀번호 암호화 백업 파일 방식

상단 ⋮ 메뉴는 v0.1.86 요청대로 **즐겨찾기 보기, 원격 저장소 보기,
저장소 접근 권한, 업데이트 확인** 4개를 그대로 유지합니다.

## 외부 네트워크 QR 작업 흐름

1. 시놀로지 또는 별도 서버에 relay 폴더의 HTTPS 중계 서버를 실제로 배포합니다.
2. TV에서 중계 서버 HTTPS 공개 도메인을 1회 등록합니다.
3. TV QR 표시 → 휴대폰 카메라 스캔 → HTTPS 열기 페이지의
   FileHub에서 열기 → 두 기기의
   6자리 확인 코드 대조 → 전송 승인 → TV 수신/복원 승인.
4. **NAS 비밀번호나 클라우드 토큰은 TV와 휴대폰 사이에서만 AES-256-GCM
   암호화/복호화**되고 서버에는 암호문만 전달됩니다.
5. 2분 이내 전송되지 않으면 만료되고, 한 번 전송 후 수신하면 삭제됩니다.

v0.1.87은 앱 **클라이언트와 중계 서버의 구현**입니다. 별도 공개
중계 서버가 배포되지 않으면 외부 네트워크 기능은 아직 사용할 수 없습니다.
동일 네트워크 LAN 전송은 서버 없이 계속 이용할 수 있습니다.

설치 요구사항: Android 8.0+(minSdk26), compileSdk36,
targetSdk35. 기존 FileHub APK와 동일 인증서 유지.
