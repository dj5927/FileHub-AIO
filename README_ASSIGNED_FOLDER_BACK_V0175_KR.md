# FileHub AIO Android v0.1.75 - 콘텐츠 지정 폴더 뒤로가기

## 변경 내용

- 홈 화면의 **추가 기능 → 동영상·만화책·소설책**에 지정한 폴더를 열었을 때 해당 폴더를 뒤로가기 경계로 기억합니다.
- 지정 폴더 아래의 하위 폴더에서는 기존대로 부모 폴더로 한 단계씩 돌아갑니다.
- 처음 진입한 지정 폴더(콘텐츠의 최상위 시작 폴더)에서 **기기 뒤로가기**를 누르면 저장소 상위 폴더로 이동하지 않고 **앱 홈으로 바로 돌아갑니다.**
- 지정 폴더 목록 화면에서 뒤로가기도 홈으로 이동합니다.
- 일반 저장소, 즐겨찾기, 원격 저장소 목록 등 추가 기능 바깥에서 연 폴더의 기존 뒤로가기는 변경하지 않았습니다.
- 로컬 메인 저장소, 원격 NAS 연결(서로 다른 계정 포함), SAF/SD/USB 및 이전 버전의 SD 문서 ID를 통해 진입한 경로를 구분합니다.
- 폴더 용도 설정, 동영상/만화책/소설책 파일 뷰어 및 공유 링크 기능에는 변경이 없습니다.

## 확인할 동작

1. 홈 → 추가 기능 → 동영상/만화책/소설책 → 지정한 폴더 열기
2. 폴더 안의 하위 폴더로 이동 → 뒤로가기 → 상위 하위 폴더 또는 처음 연 지정 폴더
3. 처음 연 지정 폴더에서 뒤로가기 → **홈**
4. 일반 파일 탐색에서 같은 저장소를 열고 뒤로가기 → 기존처럼 실제 상위 폴더

## 검증과 제한

- Android Gradle 테스트 및 Lint, 릴리스 빌드 통과. 새 단위 테스트는 로컬/NAS/SAF 폴더 계층의 경계 판정을 확인합니다.
- ADB로 연결된 실제 Android 기기가 없어 휴대전화의 뒤로가기 제스처 및 폴더 UI는 실기기 검증이 필요합니다.
- 기존 v0.1.74 APK 및 `FULL_SOURCE.zip`은 보존하고 별도 v0.1.75 앱 릴리스를 배포합니다.
