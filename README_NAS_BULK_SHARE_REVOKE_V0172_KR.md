# FileHub AIO Android v0.1.72 - NAS 공유 링크 관리 정리 / 선택 일괄 해제

## 변경 사항

- 파일·폴더 선택 → **더 보기**에는 `공유 링크 생성`만 표시합니다. 기존 `공유 링크 관리` 항목을 제거했습니다.
- NAS 원격 연결을 길게 누르면 기존 `공유 링크 관리` 메뉴를 계속 사용할 수 있습니다.
- 공유 링크 관리에서 각 링크에 체크박스를 제공하고, `전체 선택`, `선택 해제`, `링크 복사`, `선택 링크 해제` 버튼을 표시합니다.
- `링크 복사`는 체크 항목이 정확히 하나일 때만 동작합니다.
- `선택 링크 해제`를 누르면 선택된 링크 수와 NAS의 원본 파일·폴더는 삭제하지 않는다는 경고를 표시한 후 한 번 더 확인합니다.
- DSM 또는 QNAP 관리 API 인증 세션을 한 번 열고 선택된 링크를 순서대로 해제합니다. 한 항목이 실패해도 다음 링크를 시도하며 요청 개수·성공·실패·오류 설명(최대 8개)을 요약합니다.
- 공유 링크 목록은 현재 API가 조회한 최대 500개 범위에 한정됩니다. 메뉴의 `전체 선택`은 현재 화면에 표시된 항목을 뜻합니다. 필요한 경우 다른 페이지 조회 지원을 후속 버전에서 추가해야 합니다.
- 동일 공유 링크 ID가 여러 번 전달되면 중복 해제하지 않도록 dedupe하고, 선택된 공유 링크가 설정된 허용 NAS 공유 폴더에 속하는지 삭제 전에 검사합니다.
- 이미 등록된 NAS, 2단계 인증, 공유 기간/비밀번호, 연결 설정은 변경하지 않습니다.

## 검증 및 한계

- Gradle `testDebugUnitTest`, `lintDebug`, `lintVitalRelease`, `assembleRelease` 통과. 신규 일괄 해제 테스트는 중간 실패 후 작업 계속 수행, 모두 성공/모두 실패, 빈 결과를 검사합니다.
- 실제 Synology/QNAP 서버에서 여러 공유 링크를 동시에 해제하고 외부 접속 여부까지 검증하려면 기기 테스트가 필요합니다.
- 일부 요청이 NAS에 적용된 직후 네트워크가 끊어지면 해당 항목은 실패로 보고되더라도 이미 해제됐을 가능성이 있으므로, `목록 새로고침`으로 확인하세요.
