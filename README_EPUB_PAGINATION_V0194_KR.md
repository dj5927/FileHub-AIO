# FileHub AIO v0.1.94

## 수정 사항
- EPUB 페이지가 좌우로 밀리거나 인접 페이지 내용이 섞여 보이던 문제 수정
- 다음 장 첫 페이지에서 이전으로 이동하면 앞 장의 실제 마지막 페이지가 열리도록 수정
- EPUB 책갈피·읽던 위치 복원 시 페이지 경계를 반올림하여 한 페이지 이전으로 밀리던 문제 수정
- 상하단 독서 바를 숨기거나 다시 표시한 뒤에도 페이지 시작점 유지

## 기타 사항
- 실제 Dragon Raja 1권 EPUB 12·13장 원본으로 Chrome 레이아웃 비교 검증
- 기존 TXT·PDF·만화책 기능, 설정, 책갈피 유지
