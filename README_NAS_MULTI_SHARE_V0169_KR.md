# FileHub AIO Android v0.1.69: Synology 다중 공유 폴더

## 변경 사항

- NAS 관리 설정에서 하나의 File Station 경로를 직접 입력하던 화면을 **공유 폴더 목록 불러오기 · 여러 개 선택** 방식으로 개선했습니다.
- Synology DSM의 `SYNO.FileStation.List` v2 `list_share` 응답으로 서버에서 접근 가능한 최상위 공유 폴더를 표시합니다.
- 예를 들어 `01.개인자료`, `02.게임자료`, `03.영상자료`, `04.유틸자료`를 동시에 체크할 수 있습니다. 선택하지 않은 폴더에는 공유 링크 생성이 허용되지 않습니다.
- 연결 목록에서 NAS를 길게 누른 뒤 **NAS 공유 폴더 탐색**을 선택하면, 파일 전송용 SMB 연결 시작 폴더와 별도로 선택된 File Station 공유 폴더들을 열어 파일 또는 폴더 공유 링크를 생성할 수 있습니다.
- 기존 SMB/WebDAV/SFTP 탐색에서 파일을 선택하여 링크를 생성할 때는 연결 경로가 어느 공유 폴더에 속하는지 검증합니다. 정확한 매핑을 알 수 없으면 임의의 공유 폴더로 연결하지 않고 File Station 전용 탐색을 안내합니다.
- 기존 단일 공유 폴더 설정은 새 복수 선택 데이터가 없으면 그대로 읽히도록 보존하며, 기존 계정·접속 정보는 변경하지 않습니다.
- QNAP은 기존 단일 공유 폴더 경로 입력 및 공유 링크 기능을 유지합니다. QNAP 자동 공유 폴더 선택/탐색은 아직 별도 펌웨어 검증이 필요합니다.

## 새 설정 방법

1. 원격 저장소 목록 → Synology NAS 길게 누르기 → NAS 공유 링크 설정
2. 관리 HTTPS 주소와 DSM 관리 계정·비밀번호를 입력
3. **공유 폴더 목록 불러오기 · 여러 개 선택**을 누르고 `01`~`04`를 체크
4. 선택 완료 → 인증 확인 후 저장
5. NAS 연결 항목 길게 누르기 → **NAS 공유 폴더 탐색** → 파일 또는 폴더 선택 → 공유 링크 생성

## 주의 사항

- 공유 목록에는 **실제 계정이 접근 가능한 폴더만** 나타납니다. DSM File Station 계정 권한 및 공유 폴더 ACL을 확인하세요.
- 새 기능이 NAS 관리 API에 실제로 연결되는지 확인할 Synology 테스트 장비가 현재 연결되지 않았으므로 Android JVM 단위 테스트와 실물 NAS에서의 종단간 검증은 별개입니다.
- 이미 발급한 링크는 NAS가 직접 다운로드를 제공하며, 외부 접근 가능한지 별도 확인이 필요합니다.
- 신규 기능은 v0.1.69 베타이며 기존 v0.1.68과 동일한 앱 패키지/서명으로 덮어 설치합니다.
