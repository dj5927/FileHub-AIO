## v0.1.87 주요 변경 사항

- 설정 이동 메뉴를 **LAN 자동 전송**, **인터넷 QR 전송**, **파일 백업·복원**으로 구분했습니다.
- 서로 다른 Wi-Fi 또는 휴대폰 모바일 데이터에서도 TV QR을 이용해 설정을 보낼 수 있는 **클라이언트 기능을 구현**했습니다.
- TV QR을 기본 카메라로 스캔하면 HTTPS 연결 페이지가 열리며 FileHub 앱으로 이어집니다.
- 전송 전에 TV와 휴대폰의 6자리 확인 코드를 대조하고, TV에서 병합 또는 전체 교체를 최종 승인합니다.
- 전송 데이터는 AES-256-GCM으로 종단 간 암호화되며 중계 서버는 암호문만 보관합니다. 세션은 일회용이고 2분 후 만료됩니다.
- 기존 LAN 자동 검색과 앱 설정, 원격 저장소 및 사용자 자료는 그대로 유지합니다.

**중요: 인터넷 QR은 별도 공개 HTTPS 중계 서버가 있어야 작동합니다.**
이번 Release에는 시놀로지 Container Manager용 중계 서버 소스가 포함되어 있지만
서버를 운영 중이라고 가정하지 않습니다. 먼저 중계 서버를 배포하고
받는 TV에서 서버 주소를 저장하세요.

배포 안내: relay/README_KR.md

자동 테스트: Android 476개 통과, Node.js 중계 서버 테스트 4개 통과.
실제 서로 다른 네트워크에 있는 휴대폰과 TV를 연결하는 실기기 E2E 테스트는
운영 중계 서버가 없는 상태에서 수행하지 않았습니다.
