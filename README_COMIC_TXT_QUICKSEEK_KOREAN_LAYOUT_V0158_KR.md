# NAS Mount Android v0.1.58 — 만화/TXT 빠른 이동, 한국어 자연스러운 줄·페이지 경계

## 요청

1. EPUB v0.1.57에 추가된 하단 페이지/퍼센트 터치 → 전체 빠른 이동을
   만화책과 TXT 텍스트 뷰어에도 동일하게 적용.
2. TXT 소설은 줄 끝/페이지 경계에서 문장과 단어가 부자연스럽게 끊기는
   현상을 한국어 어절·구절·문장·문단을 고려해 개선.
3. 이전에 고친 페이지 간 본문 누락, 폴드 두 페이지 표시,
   글꼴·줄간격 조절 및 대용량 TXT 성능을 회귀시키지 않기.

## 만화책 · 텍스트책 빠른 이동

- 공용 ReaderQuickSeek 컴포넌트: 화면 하단 중앙의 페이지/진행률을
  터치하면 0.0~100.0%까지 0.1% 간격의 수평 슬라이더 표시.
- 선택한 위치를 움직일 때 현재 퍼센트와 예상 페이지/문자 위치
  실시간 미리보기, 이동/취소 버튼.
- 만화책은 내부 논리 이미지 페이지 기준, 접힌/펼친 화면의
  두 페이지 묶음 시작 위치도 적용하고 기존 진행률 기록에 저장.
- 만화책 하단에도 전체 읽기 퍼센트를 쪽수 옆에 추가.
- TXT는 글자 오프셋 기준으로 책 전체를 탐색. 500만 자 이하
  페이지형은 해당 위치를 포함하는 페이지로, 스크롤형은 해당
  글자가 있는 위치로, 500만 자 초과 대용량은 LargeTextBook의
  long 범위 오프셋으로 이동.
- TXT에서 폴드 펼침 두 페이지, 세로 스크롤 독서 모드도 지원.
- 기존 하단 SeekBar 바로 이동 기능과 EPUB 빠른 이동은 유지.
- 책갈피와 읽기 기록은 그대로 유지. 파일 원본은 수정하지 않음.

## 한국어 줄바꿈: Android 기본 제공 기술 확인 후 적용

- Android 공식 API: Android 13(API 33) 이상에서 TextView와
  StaticLayout.Builder는 한국어 구절 기반 줄바꿈인
  LineBreakConfig.LINE_BREAK_WORD_STYLE_PHRASE를 지원.
- 텍스트 뷰어와 페이지 분할 계산기에 동일하게
  Locale.KOREAN / PHRASE / NORMAL line break style 설정.
- Android 13 미만은 시스템의 기본 한국어 줄바꿈 기능을 이용.
- 한 줄 안에서 어절/구절 경계를 우선 고려하여 한글 단어가
  불필요하게 중간에서 끊기는 경우를 줄임.
- 페이징은 HIGH_QUALITY 대신 SIMPLE을 유지. 과거의
  HIGH_QUALITY 문단 전체 줄바꿈 최적화가 개별 페이지의
  TextView에서 재조판될 때 줄 경계를 바꾸고 아래쪽 1~2줄을
  보이지 않게 누락시켰기 때문.
- 화면으로 출력하는 TextView와 페이지 경계 계산용 StaticLayout의
  언어/줄바꿈/하이픈 정책을 정확히 맞춤.
- Kotlin/JS/외부 온라인 사전이나 별도 네트워크 API를 호출하지
  않으며 기존 앱의 오프라인 독서 특성 유지.

## 한국어 페이지 경계

- BookPaginator는 각 페이지의 실제 화면 너비/폰트/줄간격으로
  마지막으로 온전히 보이는 줄을 먼저 계산.
- 마지막 두 줄 이내에 이미 존재하는 문단 끝줄(줄바꿈 문자),
  한국어 문장 끝 기호(. ? ! … 。 ？ ！)가 있으면 그 위치를
  우선 페이지 마지막 문자 위치로 사용.
- 따옴표/괄호 닫는 기호와 인접 공백을 함께 처리하여 대화
  문장이 다음 페이지 첫머리에서 부자연스럽게 끊기지 않게 함.
- 버전 1.5의 소수점, U.S. 등의 영어 약어는 문장 종료로 오인
  하지 않도록 보호.
- 의미 있는 문장 종료 지점이 페이지 끝 두 줄 안에 없거나
  줄 수가 매우 적으면 기존 실제 표시 가능한 줄의 경계 사용.
  긴 문단을 통째로 다음 페이지에 보내 공간을 낭비하지 않음.
- 경계의 문자는 이동할 뿐, 삭제·추가·변환되지 않음.
  이전 페이지의 끝 오프셋 = 다음 페이지 시작 오프셋.
- 동일 정책을 일반 TXT와 LargeTextBook 일부 창의 페이지형에
  사용하며 폴드 펼침 두 페이지도 각각 계산.
- 기존 페이지 높이/글꼴/줄간격 변화 재계산,
  WebView가 아닌 TextView 실제 렌더링 높이 검증 유지.

## 자동 테스트

- ReaderQuickSeekTest: 첫쪽/끝쪽/중간쪽, 250억 자급 long 오프셋,
  범위 밖 입력, 0~100% 탐색 시 단조 증가.
- KoreanPageBoundaryTest: 한국어 대화 종결 따옴표, 문단 줄바꿈,
  문장 끝이 없을 때 원래 측정 경계 유지, 소수점 및 영문 약어,
  문자 연속성, 정확한 페이지 끝 처리.
- 이전 EPUB/만화/TXT 기능 회귀 자동 테스트 전체 실행.
- Android 컴파일, 단위 테스트, lintDebug, lintVitalRelease,
  assembleRelease, APK 서명과 Y 드라이브 SHA256 검증 수행.

## 주의

- 구절/어절 기반은 Android의 내장 한국어 줄바꿈 기술로, 문법 전체를
  AI로 분석하거나 원문의 오류를 수정하는 기능은 아닙니다.
- 페이지 사이 문장 종료 우선은 화면 마지막 2줄 이내로 제한되므로
  긴 문장이 페이지를 넘어가야 한다면 중간에서 이어집니다.
- 갤럭시 폴드 실기기 ADB 미연결: 실제 디바이스의 폰트 줄바꿈,
  한국어 네이티브 PHRASE 엔진, 두 페이지 렌더링 및 UI 터치
  동작은 코드/단위 테스트 이외에 직접 실기기 검증하지 못했습니다.
- 현재까지 기존 앱 설정/책갈피/읽기 기록/원본 파일/폴더 삭제 없음.
